# 3+1 帕累托主轴裁剪边界与跨盘真错价雷达门禁

Label: `wayfinder:grilling`
Type: `grilling`
Status: `resolved`
Blocked by: None

## Question

需要锁定「3 大正交帕累托极值 + 1 个宁缺毋滥真错价雷达」在真实竞彩抽水环境下的精确业务决策边界：
1. 第四席「⚡ 跨盘真错价雷达」的触发门槛（跨盘超额返还 Alpha vs 绝对正 EV）。
2. 第二席「⚖️ 期望效用极值」对 `1.01 ~ 1.45` 蚊子肉累赘腿的处置权限。
3. 第三席「🧩 容错缩水极值」的打票张数上限与 `1~2` 场退化形态。

## Answer

用户已拍板采纳全部推荐方案：
1. **第四席采用「跨盘正超额返还门禁 + 收缩防高估 + 双级诚实定性」**：先将细分盘口概率向单池 `Shin` 执行经验贝叶斯收缩并封顶高赔冷门单腿感知优势；当细分入口期望返还率显著跑赢同场最低抽水主盘基准 `>= +3.0%`（或命中同义高水差价）时激活轻仓方案（默认启用 36% 轻仓护本垫），并在徽章明确区分标注「🔥 跨盘绝对正期望 (+EV)」与「💎 跨盘低抽水洼地 (较主盘少亏 X%)」；若全盘无任何细分项跑赢主盘 `+3.0%`，严格输出 `¥0` 空仓省钱态并禁用套用按钮。
2. **第二席按锚定态区分裁剪权限**：纯盘面客观模式下允许求解器优先切换同场高性价比让球/结构入口或直接剔除 `<= 1.45` 负边际效用蚊子肉场次（全为低赔时浓缩为最优 1~2 关并说明原因）；开启「赛事雷达选队锚定」时保留用户锁定的场次不擅自删场，并在推导依据中高亮预警低赔累赘腿。
3. **第三席限最多 10 张独立实票并覆盖 1~8 场**：`3~8` 场在旋转矩阵覆盖设计 $C(v, k, t)$ 与官方标准 `M串N` 中择优最大化错场尾部保底回血（独立拆票上限 `10 张`，超限或预算不足自动切换单张官方 `M串N`）；`1 场` 为单场多赛果防冷缓冲网；`2 场` 为 `2串1` 主干配最低抽水单关回血垫（优先 `HAD/HHAD` 单关）。
