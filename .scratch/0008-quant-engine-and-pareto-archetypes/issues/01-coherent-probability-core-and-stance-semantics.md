# 五池联合闭合概率核与主观偏移重归一化策略

Label: `wayfinder:grilling`
Type: `grilling`
Status: `resolved`
Blocked by: None

## Question

需要敲定概率底座升级中的三项核心数学与业务语义取舍：

1. **全局 `fairProb` 单一事实源选择（闭合边缘概率 vs 单池独立去水概率）**：
   - 前端赔率按钮展示的「真率 %」、手动选单 `computeTruthReport`、单场微观精算 `analyzeMatchMicroQuant`（`xG`、全让球线统一一球卡盘率、半场平局率）以及同场双单关物理兼容矩阵，是否全链路统一采用闭合概率 $P_{\text{DC}}$ 作为唯一 `fairProb`？
2. **「看球直觉倾向（`纯客观 / 偏主队 / 防爆冷`）」的存废与重归一化机制**。
3. **推演沙盒「主观胜率微调滑块（`-15% ~ +20%`）」在同场多选下的概率守恒规则**。

## Answer

用户已拍板采纳全部推荐方案：
1. **全局 `fairProb` 统一收敛为五池闭合概率 $P_{\text{DC}}$**：先对单池执行 `Shin` 去水（极端边界回退 `Power` 幂次法），再以在售低抽水锚点池（`HAD + HHAD + TTG` 按返还率反方差加权，`HAFU` 在 $[0.38, 0.46]$ 内正则拟合半场占比 $\hat{\theta}$，未开售取 $\theta_0 = 0.43$）超定反演四参数 `Dixon-Coles + 二项半场稀疏拆分` $(\hat{\lambda}_H, \hat{\lambda}_A, \hat{\rho}, \hat{\theta})$，使同场五大玩法边缘概率严格闭合（仅在单场在售锚点不足 2 个奖池时回退单池 `Shin/Power`）；单池原始 `vig / payoutRatio` 保持不变，同时内部保留单池 `shinProb` 供第四席经验贝叶斯收缩使用；正式替代 `Spec 0007` 分段卡盘率补丁与同场双单关写死的净胜球权重。
2. **倾向调节全空间重归一化**：保留 `纯客观 / 偏主队 / 防爆冷` 三档开关，改为对单场底层比分联合分布施加对数优势比倾斜（Log-Odds Tilt）并严格重归一化至总概率 `1.000000`。
3. **信心滑块概率测度守恒**：按同场已选事件并集整体缩放概率（上限 `< 0.98`），未选互补状态同步反向分配剩余概率质量，已选互斥子项内部保持原条件概率比例。
