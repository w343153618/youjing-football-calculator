# Spec 0012 需求拍板记录（盲审修复 + 实战三大件 + UI 联动）

## 已由用户明确拍板的决策（Round 0 ~ Round 1）

1. **D1 · 三模奖金优化预算主权铁律**：
   - 严格锁定用户当前预算上限（`manualReport.totalCost`）做最优分配或最优减损，废除 `k * 6` 静默暴涨预算与 `Math.min(99, m)` 逻辑倍数误截断（逻辑倍数上限统一 `999`，实体店按 `99` 倍分张提示）。
   - 当用户当前本金在数学上不足以实现 100% 零倒贴时，诚实标注剩余局部回血组数（严禁贴“全选项均衡稳赚”假标签），并在界面提供 **「一键加至最低保本门槛 ¥X」** 显式升级按钮。
   - 对非互斥 `M串N` 多串过关，按联合命中状态矩阵优化最差命中场景回血底线。

2. **D2 · 3+1 精算配单满场公平对比（防“点5道菜偷上1道”）**：
   - 无锚定自由选池与雷达锚定模式下，当用户选定 $M$ 场比赛时，`① 稳健保本` 强制保留全部 $M$ 场在同一起跑线求解最优保本分配，严禁静默丢弃 $M-1$ 场。
   - 若减至核心 1~2 场能显著提升净赚率，仅在卡片底部给出文字提示（不擅自删减场次）。

3. **D3 · 素颜客观真账锁死 & 净赚/保本双口径拆解（防“十级美颜骗自己”）**：
   - 开启「偏主队 / 防爆冷」或拉动「主观胜率信心滑块（`±15%`）」时，主看板大字指标永远锁死显示 **客观期望回报率（Objective EV）** 与 **客观严格净赚率**；个人主观推演结果以独立对照小字/胶囊并列展示。
   - 将原 `profitProb` 拆分为 **严格净赚率（`netProfit > 0`）** 与 **平手保本率（`netProfit === 0`）** 并列披露。

4. **D4 · 盲审 P0 精算硬伤修复 + 国内竞彩实战三件套全量纳入**：
   - **P0 精算校准修复**：修复 `huberLagCap` 刚性泊松先验强拉子盘导致的伪 `+EV` 假阳性（改为基于真实官方 `updateTime` 滞后校验 + 跨盘等价事件同向印证）；将 `HAD/HHAD` 跨分割对齐扩展至全整数让球线（`±1, ±2, ±3`）；适配国内竞彩主盘低赔严控特征校准去水参数；修复 `¥5,000` 大额预算在 Slot ①/② 静默封顶且 `savedCash=0` 的账目黑洞；混串暗扣抽水预警补齐高抽水子盘 2~3 关场景。
   - **实战兵器 A · 胆拖过关 / 定胆（Banker Parlay）**：支持在 3 场及以上低关数自由过关中设定 `1 ~ (k_min - 1)` 场必出稳胆，直连精确注数预估、商空间状态评估、三模优化与防错打票单。
   - **实战兵器 B · 过桥配菜场寻优（Minimum-Vig Bridge Match）**：单选 1 场非单关赛事时，自动扫描全盘在售赛事推荐「最低抽水稳健过桥搭子」与「`>=135分钟` 晚场可单关反向对冲搭子」，支持一键搭桥凑 `2串1`。
   - **实战兵器 C · 实体店防坑三小件**：同义双选比价代入真实预算校验 `¥2` 整数倍离散保底（防小钱凑整反亏）；早晚场对冲安全间隔由 `110 分钟` 上调至 `135 分钟`（覆盖超长伤停补时与店面提前停售）；支持相近倍数合票压缩（Ticket Consolidation）减少店面敲机张数与变赔滑点。

## 已确认的 UI 布局协同微调项（Round 2 全部按推荐拍板 ✅）

- **D5 (Q1 · 设胆入口位置)**：将「📌 设胆」开关放置在底栏「已选场次 / 过关选择」弹窗及审单台「已选对阵明细」中（选满 `>=3` 场且存在低关数过关时启用，胆数严格 `< 最小过关数`），不塞进外层密集赔率网格，严守手机 `390px` 窄屏清爽排版；防错打票单同步标出 `【胆】`。
- **D6 (Q2 · 过桥配菜推荐交互)**：单选 1 场非单关赛事被阻断时，在底栏与审单提示卡精选展示最多 Top 2 黄金搭子（① 全盘最低抽水稳胆搭子、② 间隔 `>=135分钟` 且反向互补池开单关的时间差锁利搭子），配「一键搭上」快捷动作。
- **D7 (Q3 · 双端与安卓伴侣端同步)**：算法与 5 处嵌入式响应式 UI 一次改通并通过桌面/手机双视口实机核验后，同步重新构建最新安卓伴侣端安装包（`.apk`）。
