# 02: 商状态压缩联合状态空间评估核、守恒沙盒与 3+1 帕累托配单引擎

**What to build:**
构建基于单场 `(半场赛果, 全场比分)` 原子格点等价类折叠的商状态压缩联合状态空间 $\widetilde{\Omega}$ 精确积分器，在手动选单、`三模奖金优化`与配单方案评估中严格分离体彩店打印实票 `tickets` 与互斥中奖场景 `combos`；实现全空间守恒的看球倾向与`主观胜率信心微调`变换；并以「3 大正交帕累托极值 + 1 个宁缺毋滥真错价雷达」彻底重构智能配单引擎，提供对旧接口字段与旧枚举键的平滑向后兼容。

**Blocked by:** 01: 单场 Shin/Power 去水、四参数五池闭合校准与完场实盘校准门禁

**Status:** ready-for-agent

- [ ] 实现商状态压缩联合状态空间积分器并统一驱动手动选单、`三模奖金优化`与配单转审单评估：同场双单关（`HAD + HHAD`）、多串过关、跨实票多玩法及`旋转矩阵缩水`重叠票均在 $\widetilde{\Omega}$ 上精确积分，`TruthReport.tickets` 保持物理打印实票清单，`TruthReport.combos` 聚合严格互斥中奖场景，恒满足 `0 <= realProfitProb <= anyWinProb <= 1` 且综合抽水按实票投入本金加权。
- [ ] 看球直觉倾向（`纯客观 / 偏主队 / 防爆冷`）与推演沙盒信心滑块（`-15% ~ +20%`）统一在底层状态空间做保序倾斜并严格重归一化至全场状态概率和 `1.000000`（含同场复式多选与首场腰斩叠加场景）。
- [ ] 交付 `3+1` 四席求解器（`portfolioPlans` 与兼容别名 `fivePlans` 同步返回 4 席，兼容映射旧五流派枚举键）：
  - ① `max-profit-prob`（稳健保本）：覆盖态 100% 零`假中奖组合`约束下最大化真赚钱率；
  - ② `max-ev-utility`（期望效用）：保本护盾严格按最小整数倍 $\lceil C / u_{\text{shield}} \rceil$ 锁死（消除 4+ 场主盾倒挂），防`封顶截断`自动降阶，纯客观模式下主动裁剪 `<= 1.45` `蚊子肉累赘腿`，`雷达选队同步锚定`模式下保留场次并在推导依据首位高亮预警；
  - ③ `max-cvar-wheel`（容错缩水）：`3~8` 场在最多 `10 张`独立实票约束下融合组合覆盖旋转矩阵 $C(v, k, t)$ 与官方多串过关最大化错场回血，`1~2` 场退化为低抽水防冷缓冲网/单关回血垫；
  - ④ `alpha-radar`（错价雷达）：对细分盘口施加向单池 `Shin` 的经验贝叶斯收缩防冷门幻觉，仅在期望返还跑赢同场最低抽水主盘 `>= +3.0%`（或命中同义高水差价）时轻仓激活（默认 36% 轻仓护本垫，区分标注 `positive-ev` 与 `relative-alpha`）；无真洼地时严格输出 `available: false`、`totalCost: 0`、`savedCash: cleanBudget` 空仓诚实态；已套用 `snapshotPlan` 在同步新水位抚平洼地后保留实票重算并插入高优防坑预警。
- [ ] 按 TDD 红绿循环覆盖以上全部边界，8 场满额选单工作区单次评估耗时 `< 15ms`，全仓测试 100% 通过。
