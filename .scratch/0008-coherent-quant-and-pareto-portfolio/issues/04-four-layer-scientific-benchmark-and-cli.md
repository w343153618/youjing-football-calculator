# 04: 四层客观科学验证基准合龙（万次蒙特卡洛帕累托检验 + 账本消融回放）与 pnpm bench:quant 报表

**What to build:**
建立 100% 离线确定性运行的 4 层客观科学验证基准测试套件并纳入 `pnpm test` 强制门禁（同时新增 `pnpm bench:quant` 可读对比报表命令），用可复现数学指标证明升级后的概率底座与 `3+1` 精算配单在完场校准度、概率公理自洽性、万次随机组合帕累托前沿支配性与双轨账本抗回撤表现上全面达标。

**Blocked by:** 02: 商状态压缩联合状态空间评估核、守恒沙盒与 3+1 帕累托配单引擎

**Status:** resolved

- [x] Layer 1（完场实盘校准度检验）：在离线完场竞彩五池样本集上完整验证 `Shin + 五池闭合校准` 对比旧等比去水基线的 `RPS`、`Brier Score`、`Log-Loss` 与分桶 `ECE` 显著提升（尤其在半全场与比分高抽水池）。
- [x] Layer 2（公理与联合分布零误差不变量）：覆盖 `1~8` 场、全玩法混合、同场双单关、多串过关与`旋转矩阵缩水`，验证单场与跨场状态空间概率和、重叠兼中最高奖金、法定舍入/封顶与线性期望值误差 `< 1e-9`，且单次 8 场满额工作区评估耗时 `< 15ms`。
- [x] Layer 3（10,000 次蒙特卡洛随机组合帕累托支配检验）：采用固定随机种子在同预算利用率合法实票空间采样 `10,000` 组随机组合，在单位本金化四维目标空间 `(期望回报率 EV%, 真赚钱率 P_profit, 覆盖态保底净利比, 错一场条件保底回血率 CVaR)` 上断言前 3 档推荐方案均处于非支配帕累托前沿。
- [x] Layer 4（双轨账本配对消融回放）与报表入口：在确定性多周期盘面与赛果序列上配对回放「旧五流派等比基线」与「新 3+1 帕累托 + 空仓错价过滤 + 每日止损转模拟观察单」，验证净值回撤控制、夏普比率与累计免损增益；新增 `pnpm bench:quant` 输出结构化基准对比表，且 `pnpm test` 全量增量耗时控制在 `< 800ms` 内。
