## 1. 核心能力一览

1. **双端差异化专业排版**：
   - **手机浏览器**：100dvh 贴边原生级单手触控布局 + 240Hz 弹簧物理动效 + 8 套材质皮肤。
   - **电脑浏览器**：三栏同屏宽屏精算工作台（左看盘、中审单优化、右配流派与排雷）。
2. **内置全套图文说明书**：随时点击顶部 `📘 图文说明书` 或各面板旁 `? 图解`，查看平均优化、博热保本、博冷高弹、假中奖、抽水率、一球卡盘、时间差对冲等图文详解。
3. **五维真相审单 & 三模奖金优化**：穿透表面虚高最高奖，精确计算保底返奖、真赚钱率、水下假中奖组合，并支持一键平均优化 / 博热保本 / 博冷高弹。
4. **五大买法流派推荐**：铁盾保本流、博胆护盾流、容错防爆流（M串N防黑1场）、进球结构流、错价刺客流（内置 36% 轻仓护栏）。
5. **扫地僧小高靶向排雷**：服务端网关优先路由 `deepseek-v4.1-flash`，故障秒切 `glm-5.3-flash`，恢复自动回切。

## 2. 本地开发与验证

```bash
# 1. 安装依赖
pnpm install

# 2. 配置本地环境变量（切勿提交真实密钥至 Git）
cp .env.example .env.local
# 编辑 .env.local 填入 OPENCODE_API_KEY

# 3. 启动开发工作台 (http://127.0.0.1:5173)
pnpm dev

# 4. 类型检查与生产构建验证
pnpm build
```

## 3. 迭代发布与秒级回滚（新加坡腾讯云 `sg`）

线上采用 **时间戳目录发布 + 原子软链切换（`/opt/youjing-calculator/current`）+ systemd 高端口守护（`127.0.0.1:18768`）** 架构，自动保留最近 5 个版本：

```bash
# 一键构建、同步体彩最新实盘种子、原子发布至新加坡服务器并执行健康检查
./scripts/deploy-sg.sh

# 如新版本异常，1秒无损回滚至上一个稳定版本
./scripts/deploy-sg.sh --rollback
```

### 日常迭代规范
1. 功能开发建议在特性分支推进，合并主分支前必须通过 `pnpm build`（GitHub Actions CI 会自动拦截类型或构建错误）。
