# 0017. 三层选单状态物理隔离、三轴精算准入门禁与全分布无条件审单架构

Date: 2026-11-22

## Status

Accepted（演进并修正 `ADR-0008`、`ADR-0009`、`ADR-0010` 与 `ADR-0015` §2；其过关继承、四槽准入/排序目标、三模非单调保本证书与正交分布状态门禁进一步由 `ADR-0019` 演进细化）

## Context

`v2.7.0` 线上实机双盲走查与 `622` 场完场实盘回测揭示出选单状态流转、跨玩法映射、配单准入与审单展示之间的四重结构性失真：

1. **手选意图与已套方案共用单一 `picks` 数组引发反向污染与异步竞态**：点击「套用方案」时将求解器生成的合成单关腿与同场护盾扩选腿反向写回 `state.picks`（并按每场仅留首玩法静默丢弃同场跨玩法第 2 池票腿），导致后续在赛事雷达加场时把系统派生的高水子玩法伪造为用户亲选硬锚点，点击「还原等倍」则退化为高额复式或重触发自动合成；同时切换预算未绑定报价版本号，可在重算返回前套入旧高额方案。
2. **粗糙方向猜测、子玩法自动扩项与单关自动挂载越界**：配单层将深让球粗压为 `home/draw/away`（把 `-3` 让负误映射为客队半全场，把普通平局改买误包 `2:0/0:2` 的总进球 `0球+2球`），并在比分、总进球与半全场单选上静默补入第 2 腿拼凑高抽水笛卡尔积；右栏单关自动挂载一方面按桶内占比收下跨界 `胜其它` 造成误包，另一方面在未传预算上限下对深让球静默挂载 24 注 `¥90` 比分单；体彩解析层还将「可单关」与「可过关」合并为单一 `selling` 布尔位。
3. **雷达锚定分支跳过低阶分块且缺失整单风险准入红线**：一旦存在手选锚点，稳健保本槽位即跳过 `2串1` 分块求解并强锁满关串关（超最高关数时静默截尾丢场），且最终准入仅检查有票与不超预算，致使整单归零率高达 `99.68%` 的百倍串关仍可冠名「稳健保本」；错价雷达的 `¥16` 仓位下限亦在 `¥10` 窄预算下吃满全仓。
4. **审单驾驶舱按方案来源硬编码评分并隐藏零返奖状态**：套用方案后危险分固定取 `26 / 44 / 58` 并豁免串关抽水雪崩警告；「真实保底奖金」、「60% 高概率命中带」与盈亏推演表仅统计中奖条件子集而删去 `返奖 ¥0` 血本无归状态，五连黑概率又被 `3%` 保底截断低估。

## Decision

1. **三层选单状态物理隔离与单一在审票据视图**：在无头选单工作区中拆分为 `manualDraftPicks`（仅由用户在赛事雷达亲点修改，混合视图显式展示已选子玩法胶囊条）、`livePortfolioQuote`（绑定选单版本、预算、目标池、立场与盘口时间戳，任一输入变化立即令旧报价套用失效并由服务端二次核验）与 `appliedTicketSnapshot`（逐条票腿记录「用户亲选 / 同场护盾扩选 / 跨玩法替代 / 过桥搭子」来源）；套用方案绝不改写 `manualDraftPicks`，套用后切预算保留旧票只读并提示差额重配；对阵抽屉、小高单诊/联合会诊、常驻底栏与权威快照封存统一读取当前在审票据，「回到我的手选 / 撤销方案」精确还原草稿且不自动重挂合成单。
2. **赛果双向等价 × 串关结构 × 分动作金额授权三轴独立门禁（局部演进 `ADR-0015` §2）**：
   - **赛果双向等价**：废除 `0球+2球` 伪平局、三值方向硬猜、子玩法自动补第 2 腿及跨界 `胜其它/平其它/负其它` 混入，独立解析 `canSingle` 与 `canAllUp`；跨玩法替代逐项核验漏保率与误包率，默认自动挂载严格限定为 **100% 双向零死角等价且配平总价 `<= max(¥12, 原始手选注数 × ¥2 × 手动倍数)`**，任何部分覆盖单关或超额方案一律降为标明保住比例、漏保死角与实投金额的显式确认预览。
   - **串关结构与实盘校准红线**：用户仅选方向未锁串阶时，稳健保本与期望效用自动纳入同方向、全场次覆盖的 `2串1 / 单关` 分块竞争并醒目标注串法，超最高关数严禁静默截尾；期望效用默认按等额计划预算横向比效用并提供显式「允许留现省钱」开关，错价雷达按两元整注向下执行轻仓上限；依据 `622` 场完场实盘回测锁定三槽风险准入红线（稳健保本：`严格净赚率 >= 20%`、`整单归零率 <= 80%`、`综合抽水 <= 35%` 并强标整单归零率；期望效用锚定/子玩法：`严格净赚率 >= 3%`、`客观 EV >= -55%`；容错缩水：`整单归零率 <= 90%` 且抑制高归零 `6串1` 抢占常规盘），拒单时仅展示经整数求解或并集上界证明真正可行的降阶/最低预算/改选处方。
3. **全赛果无条件分布驱动的统一审单引擎**：手工单、配单套用与单关替代共用同一套动态危险分公式与法定风险红牌；从含零返奖状态的完整分布导出 `P(R=0)`、`P(0<R<C)`、`P(R=C)`、`P(R>C)` 四互斥桶，将条件最低派奖正名为「命中后最低返奖」，翻面披露全概率质量分位数（`P20/P50/P80`），盈亏明细表置顶插入不可展开的 `全部未中（返奖 ¥0 / 净亏 -¥本金）` 首行，并移除五连黑 `3%` 抬底。

## Consequences

- **正面收益**：彻底斩断套用回写引发的多轮子玩法雪球污染与切预算旧票竞态；保持普通胜平负 3 项半全场无死角自动配平顺滑体验的同时，杜绝深让球 `¥90` 静默挂单与漏保伪等价；同一张实票在任何入口拥有完全一致的风险评分、警告与无条件盈亏披露。
- **被拒备选**：拒绝把现金效用 `0` 设为期望效用槽的一票否决线（因官方抽水下凹对数效用由 Jensen 不等式恒负，会导致常态比赛日空仓并与错价雷达重叠）；拒绝用配单预算封顶用户显式设置的手动复式倍数；拒绝在未验证概率并集上界时盲目弹出「升级预算解锁保本」误导按钮。
