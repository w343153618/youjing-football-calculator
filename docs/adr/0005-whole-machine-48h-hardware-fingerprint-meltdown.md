# 逆向调试触发 48 小时跨浏览器硬件指纹与传染式 IP 整机熔断且仅限 SSH 解封

单次 15 分钟会话级冷却无法阻止逆向人员等待片刻或直接更换 Chrome/Edge/Safari、开启无痕窗口继续探测。我们决定将调试器/F12/重放熔断升级为整整 48 小时持久化封禁（写入服务端 `security-bans.json`），同时采集跨浏览器一致的物理硬件特征（WebGL 未掩码显卡渲染器型号、GPU 管线极限参数、物理屏幕色深尺寸、CPU 核数与时区 SHA-256 指纹）与出口 IP 双向绑定：同台电脑切换任意浏览器或无痕模式请求握手时均命中同一硬件指纹并传染封禁新网络出口；线上不设任何 Web 解封接口，唯一解封途径为管理员通过服务器 SSH 命令行清理封禁库，彻底杜绝远程撞库绕过。
