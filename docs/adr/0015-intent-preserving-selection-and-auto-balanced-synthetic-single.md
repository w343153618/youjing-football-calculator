# 0015. 意图保真无锁选号、全覆盖反比例合成单关自动挂载与凑串可逆还原架构

Status: accepted（演进并局部取代 `ADR-0007` §1 的客户端 `互斥` 置灰拒点拦截与破坏性替换救援模式；§2 跨池独立单关寻优与一次性幂等授权签名由 `ADR-0017` 与 `ADR-0019` 演进；服务端对伪造非法跨玩法串关载荷的法定拦截保持不变）

## Context

实机双视口走查暴露出原有按 `ADR-0007` §1 将体彩终端限制直接强加于选号面板的四重体验断层：① 用户仅勾选 1 场比赛时，同场其余 33 个开售选项全部置灰盖上「互斥」角标并弹报错拒点，打断改选与同义省水点击；② 单选未开单关胜平负时首屏报错 `应付 ¥0`；③ 点击「一键切换半全场合成单关」仅拆出 `胜胜+平胜`（或 `负负+平负`）两项等倍，漏防约 `5.2%` 的半场落后逆转分支且未自动反比例配平，同时把主列表 6 个主选项反向全部置灰锁死；④ 再补选第 2 场比赛凑串关时，首场永久滞留在高抽水半全场，引发 `30%+` 串关连乘抽水雪崩并污染精算配单锚定。

## Decision

1. **选号层拔除视觉互斥灰锁，改为顺滑接管 + 一键撤销**：所有开售玩法选项始终保持可点击态；若满足全单关并存条件则直接并存并锁定单关，否则在串关同场单玩法规则下点击同场新玩法时自动替换本场旧玩法并保留一步撤销缓冲，服务端底层仍对伪造跨玩法串关载荷执行 `canCheckout: false` 防御。
2. **意图与出票双层解耦的无死角自动合成单关及凑串还原**：单选 1 场未开单关方向时，`picks` 保持用户原始选号意图不变（主列表原按钮持续高亮），工作区在有效出票层（`effectiveReport`）默认自动挂载 100% 等价无死角的半全场 3 项全包（`胜胜+平胜+负胜` / `胜平+平平+负平` / `胜负+平负+负负`）并按水位反比例整数配平分倍（附 `3项无死角 / 2项搏常规 / 过桥凑2串1` 切换；仅当原赔率极低致合成等效水位 `≤ 1.00` 必亏时诚实阻断提示）；一旦用户继续勾选第 2 场比赛满足合法串关条件，因原始 `picks` 未被破坏性覆写，系统 0 毫秒自动脱去合成单关外壳并恢复低抽水原盘串关。

## Consequences

- `tests/sportteryRulesPassAndSync.test.ts` 中原断言客户端 `togglePick` 对同场跨玩法返回 `ok: false` 报错的用例升级为断言自动顺滑切换（`ok: true` 且移除本场旧池选项、支持一键撤销），服务端 `computeTruthReport` 对非法跨玩法混合数组的防御断言原样保留。
