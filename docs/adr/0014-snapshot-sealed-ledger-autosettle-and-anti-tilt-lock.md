# 0014. 出票快照封存自动对奖、局部回血诚实三态、已结亏损止损锁死与情报账本双舱解耦

Date: 2026-11-21

## Status

Accepted（扩展 `ADR-0001`、`ADR-0007`、`ADR-0011`、`ADR-0012` 与 `ADR-0013`；§1 `<= 2,048` 基础组合可重放封存与缓存盘鲜度门禁由 `ADR-0019` 补齐）

## Context

在 `v2.4.0` 实盘打磨中，围绕个人「情报与止损账本」及国内竞彩「选号—微信报单—赛中盯单—次日对奖」全链路暴露出四项核心架构与体验问题：

1. **账本无明细失忆与收盘赔率算奖陷阱**：原 `ledgerManager` 仅持久化标题、总注数与总本金，丢弃了具体对阵、让球数、出票固定水位与逐张实票拆分。若事后仅凭赛果接口返回的收盘赔率算奖，会违背中国体彩竞彩足球**「按出票打票瞬间的固定水位与让球线计奖（不受临场变盘影响）」**的法定规则，且无法拆解复式/容错单中“部分票命中、部分票未中”的真实盈亏。
2. **局部回血单二元归类失真**：原账本状态仅有 `won` / `lost` 二元划分；对于花 `¥50` 中保底票拿回 `¥36`（净亏 `-¥14`）的复式或容错单，归入 `won` 会虚增实买红单率（制造假中奖幻觉），归入 `lost` 又会抹杀 `¥36` 实际回血导致净亏损多扣 `¥36`。
3. **删单绕过每日止损护栏漏洞**：支持便捷单点删除后，若简单按 `当前存活实买单之和` 重算当日已用额度，用户一旦当天实买黑单输钱上头，只需点删除黑单即可瞬间清空当日已用额度、绕过每日止损护栏继续重注。
4. **赛前情报与赛后账本同页挤压及国内线下报单断档**：移动端第 4 页签与桌面端右栏将 40+ 场赛前单场情报流与个人止损账本纵向堆叠，查单需跨越数十张赛前卡片；同时缺少体彩官方停售红线预警、赛事编号秒搜分组以及发给线下体彩店老板的标准化微信出票口令。

## Decision

1. **出票快照封存与服务端权威完场自动对奖**：
   - 在 `add-entry` 记账瞬间将有界 `snapshot`（对阵元数据、开球时间、封存 `goalLine`、封存选项固定 `odds`、胆码标识及展开/合票后的逐张实票 `lines`）写入账本记录，同时无损兼容无 `snapshot` 的历史旧记录。
   - 服务端通过中国体彩官方完场赛果接口（`getUniformMatchResultV1.qry`，按相同数字 `matchId` 对齐 90 分钟常规时间半场 `sectionsNo1`、全场 `sectionsNo999` 与无效场次状态）调用 `server/quantEngine.mjs` 执行五池法定判奖、`GB/T 8170` 四舍六入五成双、腰斩腿按 `1.0` 乘数并降档限赔的逐票精确结算；手工改派奖标记 `manualOverride: true` 的记录受保护不被自动覆盖，支持一键恢复自动对奖。
   - 当待开奖串关前序场次已官方完场全红、仅余末场未开赛且当前实盘互补池开放单关时，在账本快照上直接挂接实时 `liveEarlyHedge` 锁利/减损补单提示。
2. **诚实四态账本生命周期（`pending` / `won` / `partial` / `lost`）**：
   - 已结订单严格区分：`settledReturn >= cost` 为 `won`（真红单/保本单，计入 `liveWinRatePct`），`0 < settledReturn < cost` 为 `partial`（局部回血单，如实核算 `netProfit = settledReturn - cost < 0`，单独统计 `livePartialCount` 而不虚增红单率），`settledReturn === 0` 为 `lost`（黑单）。模拟观察单同理按 `paperRefCost - simulatedReturn` 精确累计未买免损净额。
3. **防上头已结亏损额度锁死 + 5 秒软撤销缓冲**：
   - 删除当天 `pending`（误记/未出票撤单）或净盈利实买单时，立即退回当日止损额度；删除当天已开奖且净收益 `< 0`（`lost` 或 `partial`）的实买单时，将该笔本金锁入当日 `dailyLockedLogs`（北京时间 `00:00` 随自然日自动清零），且若用户在 5 秒内点击「撤销」恢复该单，自动解除同 `entryId` 锁记录确保零重复计费。
4. **双舱解耦与国内竞彩实操闭环**：
   - 第 4 页签拆分为 `📒 双轨账本`（默认首屏，含实买红金实线章 vs 模拟虚线水印章及四态胶囊筛选）⇄ `🧹 小高情报舱` 分段切换，桌面端右栏升级为 `③ 审单 | 📒 账本 | 🧹 情报` 三段切换；
   - 补齐①赛事雷达编号/队名秒搜、按比赛日分组折叠与体彩官方停售倒计时徽章，以及「🧾 防错打票单」内的一键复制发体彩店主微信口令与快捷记账入口。

## Consequences

- **正面收益**：账本从手工记数的流水表升级为自动盯赛果、自动算局部回血、赛中提醒早场红单锁利的闭环实票夹，同时堵死删单破止损漏洞并打通国内微信找体彩店主出票的最后一公里。
- **维护约束**：全部五池赛果判定与法定算奖严格留在 `server/quantEngine.mjs`，前端零算奖公式泄露；`ledgers-db.json` 快照执行严格体积与条数清洗上限（单记录 `<= 15` 场、`<= 512` 票），确保磁盘持久化轻量稳定。
