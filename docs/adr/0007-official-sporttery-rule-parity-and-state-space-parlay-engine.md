# 0007. 中国体彩法定选号互斥状态机与多串过关互斥赛果空间精算架构

Date: 2026-11-18

## Status

Accepted

## Context

在实际购彩场景中，用户在赛事雷达上下滑动选号或跨页签审单时，必须随时掌控「过关方式」与「倍数」两大核心杠杆，且所有选号动作必须 100% 遵循中国体彩官方计算器（`m.sporttery.cn`）的出票法则：
1. **同场跨玩法互斥**：如同一场比赛选了 `[0]` 胜平负的「胜」，绝不可在串关中继续勾选同场 `[+1]` 让球胜平负的「平」或同场比分/总进球/半全场（仅全单均开单关且锁死「单关」模式时可分票单买）；
2. **玩法最高关数与场数红线**：串关最多 8 场（超 8 场须全单关且仅算单关），总进球最高 6 关，比分与半全场最高 4 关，单场未开单关时投注额与奖金须归零禁出票；比分玩法须完整覆盖全部 31 个官方选项（含胜其它、平其它、负其它）以保证返还率与去水真率不失真；
3. **自由过关多选与 M串N 多串过关的概率陷阱**：当用户在 4 场比赛中选择 `2关+3关` 或 `4串11`（共 11 注）时，各注之间共享底层比赛赛果、呈强正相关。若直接将 11 注各自的中奖率相加，会出现总中奖率突破 100% 的数学谬误，且无法识别“仅中 2 场低赔时实派低于 11 注总本金”的多串假中奖风险；
4. **等倍与智能不等倍的状态共存**：底栏常驻「倍数」在启用三模奖金优化或套用五流派不等倍方案时，若仍显示单一统配倍数会产生语义冲突。

## Decision

1. **双端同源体彩法定选号门禁**：在客户端点选入口（即时视觉互斥置灰、未开盘 `[未]` 禁用与防误触震动提示）与服务端 `server/quantEngine.mjs` 精算内核同时执行中国体彩法定规则校验（同场单玩法互斥、双单关强制锁死单关、8 场串关上限、`HAD/HHAD:8 / TTG:6 / CRS&HAFU:4` 关数限流、未开单关单场 0 元拦截、31 项全比分归一化）。
2. **互斥赛果状态空间枚举法（Mutually-Exclusive Match-Outcome State Space）**：在 `server/quantEngine.mjs` 中，针对任意自由过关组合（`1~8关` 多选）或官方标准 `M串N` 多串过关（`3串3` 至 `8串247`），先按体彩法定规则生成全部基础实票注单（逐注执行 `四舍六入五成双` 与对应关数的 `10万/20万/50万/100万` 单注封顶），再枚举 $M$ 场比赛的互斥赛果状态（每场处于「命中某一所选选项」或「未命中」），对每一互斥状态汇总同时命中的全部注单派奖。由此一次性精确推导出与官网分毫不差的 `理论最高奖金`、真实的 `最低命中回血`、绝不超 100% 的精确 `命中任一注真率`、剔除多串倒贴后的 `真赚钱率` 与 `假中奖组数`。
3. **全局常驻双态投控栏与五流派选队锚定**：桌面端底部横跨三栏固定常驻投控总栏，移动端/安卓端在四页签底部常驻（赛事与审单页完整展开、五流派与账本页紧凑常驻可点开），内嵌过关选择浮层与九宫格倍数键盘，并在启用三模优化/五流派时自动切换为「智能分倍态（支持整单按比例倍增或一键还原等倍）」；五流派新增「一键匹配赛事雷达已选球队」按钮，在同步 `1~8` 场次的同时将用户已选球队方向作为流派生成主锚点。

## Consequences

- **正面收益**：彻底根除“选了胜还能乱点让球平”、“未开单关单场算出假奖金”、“含比分选出 5串1”等违背体彩实体店规则的 Bug；用户在任意位置滑动或切页均能一眼看到并操控过关与倍数；多串过关的假中奖与真赚钱率达到严格精算级准确度。
- **代价与约束**：互斥赛果状态空间在极端多场多选（如 8 场全包）下分支数呈指数增长，服务端内核须在超出阈值时启用精确极值保留 + 高概率主干截断保护，确保单次密文精算响应严格稳定在数毫秒内。
