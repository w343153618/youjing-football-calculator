# 纯数学概率引擎与“扫地僧小高”情报层解耦及主备模型自动回切

我们决定将底层概率/优化数学引擎与 AI 情报层完全物理隔离，并在所有用户可见界面统一以“扫地僧小高靶向排雷”呈现（绝不暴露底层模型品牌字样）。底层推理网关接入 OpenCode Go（`https://opencode.ai/inference/go/openai/v1`），采用主备高可用自动回切策略：所有请求始终优先调用 `deepseek-v4.1-flash`；一旦遇到超时、限流或上游不可用，立即自动无感切换至备选模型 `glm-5.3-flash` 保障连续可用，并通过冷却重探机制在 `deepseek-v4.1-flash` 恢复后第一时间自动切回主模型。AI 输出仅提供靶向排雷点评、定价消化度（Price-In）研判与主观微调建议，须经用户确认后才进入推演沙盒，杜绝“双重计价（Double-Counting）”污染客观水位概率。
