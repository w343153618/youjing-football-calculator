# 纯数学概率引擎与 DeepSeek 联网情报层物理隔离

我们决定将底层概率/优化数学引擎与 DeepSeek 大模型情报层完全解耦：大模型的输出绝不自动覆写客观隐含胜率或直接参与奖金优化计算，且必须前置实时联网搜索源（RAG）再交由 DeepSeek 提炼。这是因为体彩实盘水位本身已包含精算师对已公开信息的定价，若让大模型读取新闻后直接二次扣减/上调水位概率，会导致严重的“双重计价（Double-Counting）”失真；同时 DeepSeek 官方接口默认无实时联网能力，裸调会产生伤停幻觉。因此，AI 层仅负责输出带信源的靶向排雷提示、结合水位快照研判“定价消化度（是否处于体彩调水滞后窗口）”，并提供可选的胜率修正建议值，须经用户显式点击确认后才注入主观信心滑块参与沙盒推演；未配置 API Key 时系统可无损降级为纯数学模式运行。
