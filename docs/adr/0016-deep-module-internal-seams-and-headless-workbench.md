# 0016. 精算引擎纯内存内部接缝、组合式无头工作台、权威快照单点封存与说明书同源架构

Date: 2026-11-21

## Status

Accepted（演进并深化 `ADR-0002`、`ADR-0004`、`ADR-0008` 与 `ADR-0014`）

## Context

历经 `v2.1.0`～`v2.6.0` 连续六轮精算校准、双轨账本自动对奖与意图保真无锁选号迭代，五处热点文件累积出显著的架构摩擦与重复维护税：

1. `server/quantEngine.mjs` 膨胀至 18,336 行，将体彩盘口/完场赛果网络抓取、磁盘缓存及 545 行静态兜底赛事与纯确定性数学计算混写在同一模块内，且离散反比例分倍循环（4 处，其中 `solveZeroUnderwaterDutching` 已出现上界与平手提拉边界漂移）及派奖报告/原子概率重对齐管线（4 处）存在多份复制副本。
2. `src/mobile/SkinPhoneApp.tsx` 单组件函数膨胀至 7,479 行（56 个 `useState`），将双轨账本、每日止损护栏拦截、5 秒软撤销、扫地僧小高会诊状态以及选单派生可玩性门禁全部困在 DOM 闭包内（迫使部分测试用 `fs.readFileSync` 扫描源码字符串）；同时 `src/workspace/betSlipController.ts` 在非客观立场下发起双重 `/api/quant/compute` 加密往返，并寄生了 327 行无关的说明书目录搜索代码。
3. 出票快照封存拆票与法定关数校验在客户端选单控制器、安全网关 `/api/ledger/mutate` 与账本管理器三处重复实现；`server/securityShield.mjs`（1,777 行）在 48 小时整机熔断天平与加密信封职责之外混入了大量账本与小高业务编排。
4. 说明书每更新一条业务规则需在 4 个位置手动同步，且 `src/manual/UserManualModal.tsx`（2,025 行硬编码章节 JSX）已出现残留旧互斥提问胶囊的口径漂移。

## Decision

1. **纯化精算黑盒门面与高内聚内部接缝**：将体彩水位快照与完场赛果抓取/磁盘缓存及静态兜底数据剥离至独立 `server/sportteryFeed.mjs`，使 `server/quant/` 下辖的法定规则与唯一离散分倍器、五池联合闭合校准、商集状态空间积分、`3+1 精算配单` 及统一派奖评估与自动对奖五大内部子模块保持 100% 零 I/O 纯内存计算；主门面 `server/quantEngine.mjs` 收敛至 600 行以内的工作区编排入口，清理零引用死代码并保留科学回测与神谕断言所需的命名重导出。
2. **1-RTT 立场对照与组合式无头工作台深模块**：服务端在主观立场计算时单次附带返回客观对照配单以消除客户端二次往返；保持 `BetSlipController` 聚焦选单工作区与全部派生可玩性门禁，新增组合式无头工作台控制器通过注入端口（加密 RPC 生产适配器 / 内存测试适配器、存储、时钟）统一承载双轨账本、每日止损护栏、软撤销与小高会诊状态；`SkinPhoneApp.tsx` 退化为薄响应式壳与 5 个纯渲染业务舱视图，并以内存行为断言全面替代源码字符串正则测试。
3. **出票快照服务端单点权威封存与安全网关职责归位**：客户端仅保留轻量即时预览，由服务端唯一权威快照封存实现共享单一 `POOL_MAX_PASS` 完成实票展开与固定水位定格；`server/securityShield.mjs` 回归 48 小时整机熔断天平、会话加密信封管线与 `/api/health` 四端版本门禁，业务路由编排抽离至独立应用路由模块由 `runtimeApp.mjs` 统一组装。
4. **说明书目录归位与服务端铁笼同源派生**：将客户端说明书目录与搜索归位 `src/manual/` 并以结构化章节数据驱动渲染弹窗；在 `server/manualQaEngine.mjs` 内部由结构化精编知识源自动派生 Engine-2 系统规范摘要，同时将防刺探正则与累计违规锁号严格隔离在服务端。

## Consequences

- **正面收益**：五大巨型热点文件全面瘦身为窄接口深模块，分倍器、算奖报告、出票快照与说明书口径各自实现单点局部性（Locality）；选单、账本、止损与小高全链路均可在无 DOM 的 `node --test` 内存适配器下毫秒级验证；主观立场切换网络往返减半。
- **被拒备选与边界约束**：拒绝将大文件机械切碎为数十个宽签名浅层辅助文件；拒绝为 `xiaogaoCore.mjs` 与 `manualQaEngine.mjs` 单独拆分新的底层大模型传输文件，以维持 `scripts/check-guardrails.mjs` 最小化的厂商名保密白名单。
