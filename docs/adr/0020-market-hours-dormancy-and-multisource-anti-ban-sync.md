# 0020. 竞彩开休市静默门禁、真实协议栈指纹持久化与多源无规律防封同步网关

Date: 2026-11-25

## Status

Accepted（2026-11-26 修订开市全时段约 20 分钟稳态同步、官方盘 35 分钟防降级护栏与本机轻节点双通道签名推送；演进并补充 `ADR-0001`、`ADR-0018` 与 `ADR-0019`）

## Context

现网实盘与历史采集存在四项影响长期防封稳定性的结构问题：

1. **双路未协同高频请求与裸连特征**：`appRoutes` 在缓存满 `120s` 或用户点击刷新按钮时使用无浏览器握手指纹的裸 `fetch` 直连单一官方接口，同时后台 `collectorWorker` 按 `30s~180s` 昼夜轮询且冷启动历史回补每 `4s` 连续触发，在境外机房出口（`malaysia-hostinger`）下极易暴露机器周期与 Node `undici` TLS/HTTP2 指纹特征。
2. **休市期无效轮询暴露机器作息**：北京时间每日早间 `11:00` 前及夜间官方停售（`vtoolsConfig.offLineSaleStatus !== 1`）后并无在售水位变动，继续轮询既浪费配额又直接暴露全天候自动化脚本特征。
3. **单一域名依赖与“假 200”脆弱性**：仅依赖单个域名缺少公开备份源分摊与故障秒切能力；而若简单将慢半拍的第三方镜像盘直接覆盖主盘，又会导致旧水位倒盖新水位或缺失体彩终端单/串关法定售权签名（违反 `ADR-0019` 实票售权门禁）。
4. **跨境出口潜在地域限流风险**：海外服务器直连国内站点偶遇跨境链路抖动或地域限流时，需要预留零侵入的国内轻节点签名推送兜底口。

## Decision

1. **全站唯一防封出网网关与真实浏览器协议栈持久化**：
   - 废除路由层旁路直连与 `4s` 高频回补定时器，所有外部赛事、水位、赛果与历史回补请求统一收口至单一防封同步网关（单次并发严格锁死为 `1`，内置每域名滑动窗口硬限流与 `ETag`/`If-Modified-Since` 条件缓存）。
   - 采用真实浏览器 TLS（JA3/JA4）与 HTTP/2 帧指纹引擎（`impit`）替代裸 `undici` 握手，并在 `node:sqlite` 按域名持久化固定 `zh-CN` 浏览器身份与访客会话 Cookie（30 天内保持同一浏览器身份，严禁逐次随机换 `User-Agent`，仅在受阻率超阈值时轮换），配合 Soft-Block（假 `200` 空壳/维护页）检测与每域名历史成功率账本（`tier_history`）。
2. **开休市静默门禁与约 20 分钟稳态无规律随机抖动**：
   - 北京时间每日 `00:00 ～ 11:00` 强制 `0` 外网请求；`11:00` 后叠加非整点随机苏醒偏移，在每日中国体彩官方计算器可用开市窗口内（直至晚间官方返回 `offLineSaleStatus !== 1` 或当日在售场次全部截止后，周中 `22:10` / 周末 `23:10` 兜底），**无论当时是否存在活跃看盘会话**，均取消闲置慢检降频并稳定保持约 `20 分钟` 一次的同步节拍，确保成员随时首次打开工作台即为当天最新盘面；夜间停售后除未结账本注单低频核对完场赛果外整晚进入 `0` 请求休眠。
   - 彻底废除固定整数分钟刻度与 `:00/:15/:30/:45` 整刻钟对齐：每次轮询间隔在宽幅连续区间（`18分 ～ 22分` 叠加非整秒毫秒尾数）内采样，并对落入整刻钟 `±35 秒` 邻域的目标时刻自动施加非对称偏移；前端手动刷新在休市期 `0` 外网请求，开市期距上次成功同步 `< 5 分钟` 直接秒回内存快照。
3. **五源健康池真随机分流、单调时间锁、35 分钟官方盘防降级与实票前官方核对**：
   - 内置 5 个独立公开免登录源（中国体彩 PC 与移动双通道 + 3 个国内公开竞彩备份源），常规同步从健康未冷却源中随机抽取 1 源，遇超时/`403`/`429`/`5xx`/空壳 **0 重试立即切换下一健康源**并对故障源执行阶梯冷却（`30m → 2h → 6h`）；本机滑动窗口自限流保护与正常含赛程页面的静态风控脚本均不得误判为上游故障冷却，且盘面/赛果单飞锁须严格在异步流结束后释放。
   - 只要当前持有的中国体彩官方实盘（`official-live`）处于 `35 分钟` 鲜活有效期内，手动点击刷新或本地多源拉取**绝不允许**用不含法定售权的第三方「多源备份同步盘」倒盖降级当前官方盘；仅当官方盘缺失或断推超时 `>= 35 分钟`（如推送工作站合盖休眠）时，海外多源备份同步盘方自动接管拉新，并在后续官方推送恢复时无缝升回权威盘。
   - 跨源合并严格按「官方周编号 + 主客标准队名」对齐并执行分池时间戳单调防倒退锁（备份源缺冷门子池时保留上次已知子池并标明）；当成员触发「店主出票口令」或封存「实买单」且当前底盘非新鲜官方源时，在限流保护下自动执行一次官方权威报价与单/串售权核对。
4. **HMAC 验签快照推送接收端点（本机轻节点直推，零国内云服务器依赖）**：
   - 服务端内置带时间戳防重放窗与 `HMAC-SHA256` 验签的快照接收接口（同步放行合法验签推送请求，不受无浏览器头拦截），同时支持在体彩开市可用窗口内接收由操作者本机 macOS 工作站（`launchd` 轻量任务，严禁碰任何南京或国内云服务器转发）每 ~20 分钟直采推送的中国体彩官方在售盘面与近 3 日官方完场赛果快照。

## Consequences

- **正面收益**：每日外网总请求压缩至白天开市期约 `25~38` 次且均摊至多域名（单域名日均不足 `8` 次），消除凌晨机器轮询、整刻钟周期律、Node 裸 TLS 握手与频繁换 UA 四大风控特征；备份源掉线或改版零中断自愈，且 `100%` 守住 `ADR-0019` 实票防错价红线。
- **被拒备选**：拒绝每次请求随机更换 `User-Agent`；拒绝接入验证码破解平台或大模型猜赔率；拒绝让前端刷新按钮或后台历史回补绕过开休市与滑动窗口限流；拒绝将缺少法定售权的第三方慢盘直接冒充官方实票出单。
