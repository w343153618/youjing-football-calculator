# 说明书智能问答采用「本地精修词库 + 受限边界解释器 + 违规超 4 次自动锁号」混合铁笼架构

若完全不接入语义解释器，用户针对「主观胜率滑块往左拉 -8% 在串关里怎么看」等个性化追问无法获得贴合场景的举例；若直接裸接通用大模型，则面临胡编乱造非本 APP 功能、消耗配额以及被竞品套取底层模型名称与内部机密的风险。因此我们采用三道铁笼混合双擎方案（Route C）：常见高频功能与专有名词由本地精修说明书知识库 0 毫秒零成本秒答；长尾组合追问强制注入《本 APP 唯一官方功能边界》并开启双向敏感词脱敏；任何刺探模型身份/源码/提示词或超出说明书范畴的无关提问均由前置与语义双闸门拦截警告，2 小时内累计违规超过 4 次（第 5 次触发）立即自动锁死该成员账号并同步触发 48 小时整机熔断封禁。
