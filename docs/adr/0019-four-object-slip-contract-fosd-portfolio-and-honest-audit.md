# 0019. 四对象选单契约、FOSD 单调配单与非单调保本证书审单架构

Date: 2026-11-23

## Status

Accepted（双模型三轮实机与离散反例联审零分歧签署；局部演进并修正 `ADR-0010`、`ADR-0013`、`ADR-0014`、`ADR-0015` 与 `ADR-0017`）

## Context

基于线上生产双视口（`1520×920` / `390×844`）多轮实机点测、16 场官方在售盘 `108` 格矩阵复算与离散整数规划反例验证，定位到既有状态隔离、推荐准入、奖金优化、单关替代与审单披露中的五类结构性缺陷：

1. **处方动作、奖金优化、同义替换与单关裁剪可越权篡改在审票面**：`lower-pass-preview` 未验证新旧关数即冠名“降阶”，并在客户端丢弃预览票行将手选 `passSpec` 重置为 `auto`（回退最高关 `4串1`）；右栏三模优化恒读 `manualReport`，将已套用的 `¥10` 配单偷换回手选底稿；同义替换清除同场非目标玩法全部选项（误删未参与合并的 `客胜`）并暗改全局倍数；合成单关 `trim-2way` 跨场继承且变价同步缺金额锁；满关/多串设胆静默改关数引发金额剧变。
2. **逐票覆盖整单本金硬约束 + `3%` 过低红线 + 绕过目标的支配预剪枝制造高归零彩票**：原分块器要求每票独立覆盖整单总本金（$\sum 2/u_i \le 1$），将常规防平双选 `2串1` 分块与 `4串6` 容错网在候选生成阶段提前淘汰，再由 `3%` 严格净赚门槛（主观倾向甚至可放行客观 `2.19%`）端出 `96.2%` 归零率的 `4串1`；且默认预剪枝未比较对数效用 $U$ 误删更优配比；同时若在回血排序式中仅惩罚 $L_{\text{part}} = \mathbb{E}[(1-r)\mathbf{1}_{0<r<1}]$，会在 $r=0 \to r>0$ 边界产生逐态多返却降分的非单调逆序。
3. **重叠票保本门槛虚高、预算可行性非单调与多串三模克隆**：同场全包 `2串1`（7 票 `¥42`）因必共中关系本就存在整数配比使所有中奖态至少返 `¥47.76`，且 `≤ ¥44` 内仅 `¥26, ¥38, ¥42, ¥44` 可行（`¥38` 可行而 `¥40` 无解），证明逐票独立充分条件与预算二分法均不成立；同时多串重叠分支在未覆盖整单本金前共用补最弱桶路径，导致三模式克隆且压低高关返奖。
4. **选号资格与分布计算状态混用、票张数假估算与单场跨池降本漏算**：单场待配（`¥0`）渲染 `0.0%` 归零率，而 `> 2,048` 注超限阻断单渲染 `100%` 归零率；不等倍方案把逻辑行数当 `2元` 注数，手选合票用 `ceil(N/3)` 假估算（`8张` vs 印单 `24张`）；深盘受让（如 `-2让负`）单池需铺 21 种比分（`¥66~78`），漏掉了同覆盖 `6项半全场 + 3种比分`（`¥20~22`）的跨池独立单关方案。
5. **沙盒污染、跨日时间差倒置、受让盘方向写反与大单封存缺快照**：模拟腰斩仅改赔率 `1.0` 未将作废腿移出命中事件与有效关数（单关作废误报全损）且模拟值流入底栏与打印页脚；跨日开球忽略完整日期将 `1,425 分钟` 算成 `15 分钟`；`+1` 客强盘卡盘文案硬编码“慎追让胜穿盘”且 `-2` 深盘把让平混入穿盘率；账本在 `513..2,048` 基础注区间跳过 `snapshot` 构造却仍返回 `sealedFromWorkspace: true`。

## Decision

1. **四对象单向状态契约与显式锁关继承（方案 B2，演进 `ADR-0017` §1）**：
   - 工作区状态严格分离为 `manualDraft`（我的手选）、`portfolioQuote`（中栏推荐预览）、`activeSlip`（右栏、底栏、打票单、微信口令与双轨账本唯一共享的核对出票对象，绑定票据修订号）与 `sandboxSim`（假设推演）；按账号版本化本地持久化 `manualDraft`（恢复时重验开售、让球、SP 并作废旧授权）。
   - 废除模糊的 `"auto"` 过关名，未手动选关时显式定名为 `follow-max-parlay`（中栏可自由寻优低阶结构）；一旦用户显式选定自由关、固定多串或胆码，锚定三槽默认完整继承该约束（增删至 `3..8` 场持续保持意图，不合法时显式标受阻），无解时仅提供零副作用的「比较其他合法过关」独立预览（唯当 $\max(k_{\text{new}}) < \min(k_{\text{old}})$ 称“全部降阶”），确认后原子替换 `activeSlip`。
   - `单关` 页签统一按“存在当前可售、可单、合法 SP 选项”过滤，禁点不可单主盘格，空草稿或兼容单关草稿首次选可单项默认设为 `[1]`。
2. **客观硬准入、总本金缺口 $D$ 单调排序与严格 `3+1` 四槽体系（修正 `ADR-0017` §2）**：
   - 所有概率、亏损与 EV 准入门禁 **100% 仅用五池校准客观分布判定**；废除 `paretoPortfolio` 绕过目标的支配预剪枝，按联合状态返奖向量计边际；每保留子串 $E$ 完整覆盖 $\prod_{j \in E} T_j$（或 $T \triangle S = \varnothing$）；允许不同目标共优时共享同一最优实票并明标共选。
   - **槽① `稳健保本 / 稳健护本`**：Tier-1A 对所有规则可达中奖态验整分 $R_s \ge C$，初筛 $p_+ \ge 0.20, p_0 \le 0.75, \text{EV}_{\text{obj}} \ge -0.35$，按 $\operatorname{lexmax}(p_+, p_=, \text{EV}_{\text{obj}})$ 排序；仅当 Tier-1A 无解时启用 Tier-1B（初筛 $p_+ \ge 0.25, p_0 \le 0.60, L_{\text{part}} \le 0.12, P_{\text{obj}}(0 < r < 0.5) \le 0.05, P_{\text{obj}}(0 < r < 0.8) \le 0.25, \text{EV}_{\text{obj}} \ge -0.35$），以总本金缺口 $D = \mathbb{E}_{\text{obj}}[(1-r)_+] = p_0 + L_{\text{part}}$ 构造单调目标 $J_{1B}^* = p_+ + 0.25 P_{\text{obj}}(r \ge 0.8) - 0.50 D + 0.08 \text{EV}_{\text{obj}}$ 并强制改标 `"允许局部回血 · 非保本"`。
   - **槽② `期望效用`**：初筛 $p_+ \ge 0.18, p_0 \le 0.80, L_{\text{part}} \le 0.16, \text{EV}_{\text{obj}} \ge -0.40$，以单调饱和斜坡 $g(r) = \min(1, \max(0, (r-1.2)/1.6))$ 与 $D$ 最大化 $J_2^\* = \mathbb{E}_{\text{obj}}[\ln(1 + 0.65(R-C)/B)] + 0.22 \mathbb{E}_{\text{obj}}[g(r)] + 0.15 p_+ - 0.25 D$。
   - **槽③ `容错回血`**：初筛 $p_0 \le 0.75, p_+ \ge 0.12, P_{\text{obj}}(r \ge 1.15) \ge 0.10, \text{EV}_{\text{obj}} \ge -0.40$，按 $\operatorname{lexmin}(p_0, -\operatorname{ES}_{0.25}^-(r \mid r > 0), -\mathbb{E}_{\text{obj}}[\min(r, 1)], -p_+)$ 排序，逐幸存子集验证存活保证。
   - **槽④ `错价雷达`**：单腿 $O \cdot p_{\text{shrunk}} \ge 1.01$ 且最终整数倍封顶取整后客观与收缩双口径净期望均为正，否则空仓。
3. **固定 `activeSlip` 的可执行域 $\mathcal{E}(N)$ 三模优化与非单调保本证书（演进 `ADR-0013` §1）**：
   - 三模优化只读当前 `activeSlip` 与当前实投 $C = 2N$（含固定多串等倍与固有重数约束 $\mathcal{E}(N)$，后处理零改倍，$p_0$ 恒定不变），按逐票单位整分返奖向量 $a_{s,\cdot}$ 归并可达中奖态 $s \in \mathcal{S}_+$。
   - 定义 $F(N) = \{m \in \mathcal{E}(N) : (a_s - 200\mathbf{1})\cdot m \ge 0, \forall s \in \mathcal{S}_+\}$，独立返回 `C_min`、三态 `isCurrentFeasible`（`certified-feasible / certified-infeasible / unknown`）与 `C_next`，禁止用预算二分法或把超时当无解；平均、博热、博冷分别按分段字典序目标寻优。
4. **右栏三层审单、多重集双射拆合票、跨池独立单关与沙盒/封存隔离（演进 `ADR-0014`、`ADR-0015` & `ADR-0017` §3）**：
   - 右栏固定按「① 当前核对实票（`K` 种基本票 · `Σm` 份 2 元注 = `¥C` · 预计终端纸票 `Z` 张）→ ② 四桶客观概率分布 → ③ 赛果推演明细（置顶 `整单无中奖票` 拆分全未中与未成票 + 默认概率降序 + 按命中场数折叠 + 回链中奖票 `#ID`）」三层展示；统一拆合票函数强制满足 $\operatorname{multiset}(\operatorname{expand}(\text{slips})) = \operatorname{multiset}(\text{basicBetsWithMultiples})$。
   - 正交拆分 `selectionStatus × distributionStatus`（`2,048` 按展开后含固定多串固有重数的基础注计）；单场救援纳入跨池独立可售单关（允许互斥或合法重叠）并将授权一次性幂等绑定票行、倍数、覆盖、版本与金额；同义替换须同时校验单场事件相等与整单联合命中支持相等。
   - 具名 `voidMatchIds` 逐原基本票退出命中判定与有效关数（全腿作废退该票本金），沙盒只进情景对比卡；跨日对冲按完整北京时间计算 $W = t_{\text{cut}} - t_{\text{done}}$；卡盘温度计按 $z = -\operatorname{sgn}(g)d$ 区分 $z = |g|$ 让平与 $z > |g|$ 真穿盘；账本支持完整 `<= 2,048` 基础组合可重放快照验证后再返回封存成功，全站统一披露 `boardState / source / quotedAt / syncedAt / quoteVersion`。

## Consequences

- **正面收益**：根除处方升关、优化换底稿、同义吞客胜、单关串场扩额、设胆暗涨价、腰斩假全损、跨日倒置与大单缺快照等全部高危隐患；在保持零倒贴高净赚优势盘口的同时，彻底消灭 `3.8%` 净赚率四串彩票推荐。
- **验证要求**：单日矩阵参数作为可复算政策初值，后续随历史归档积累执行跨比赛日时间切分样本外校准。
