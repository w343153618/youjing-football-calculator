# 0013. 预算主权守恒、素颜客观指标锁死、全让球线滞后实证校准与胆拖过桥实战架构

Date: 2026-11-21

## Status

Accepted（基于 826 场中国体彩完场真盘含 204 场外部零污染盲测集与 42 场实时盘口交叉盲审，修正并扩展 `ADR-0010` 与 `ADR-0012`；§1 可执行域 $\mathcal{E}(N)$ 三模优化与非单调保本证书由 `ADR-0019` 深化修正）

## Context

在引入仓库区间外的 204 场中国体彩完场实盘、42 场在售实时盘口及 1,080 组极限复式对 `v2.3.0` 执行独立红队科学盲审后，查明六处需要架构级修正的精算、诚实性与国内竞彩实操断层（其中第 2、3 项显式修正 `ADR-0010` 局部假设）：

1. **三模奖金优化违背用户预算主权与 `99倍` 逻辑误截断**：原三模优化默认按 `k * 6` 静默将用户预算暴涨 `3 ~ 5.15 倍`，在博热/博冷模式未联立求解总成本膨胀后的护盾保本线，在修复器中将逻辑倍数硬截断为 `<= 99`（摧毁千元大额注单反比例配比），且在非互斥 `M串N` 或预算不足仍存假中奖时无条件输出“彻底消灭假中奖倒贴”标签。
2. **单向泊松截断器伪造实盘 `+EV` 与深让球盘对齐断层（修正 `ADR-0010` §2）**：原校准器在子盘去水概率低于刚性泊松先验超过 `3.2%` 时，无论子盘时间戳新旧均强行向泊松先验拉高 `85%`，在实盘（如 `周五008` 比分池已最新定价 `2:1` 而非 `1:0`）上凭空制造伪 `+EV` 信号；同时主让球跨分割对齐仅处理 `|goalLine| == 1` 而遗漏 `±2 / ±3` 深让球盘，且主盘全额照搬欧洲 `Shin` 去水高估了国内竞彩 `<1.55` 超低赔大热的返还率。
3. **无锚定 `稳健保本` 静默丢弃场次、平手充净赚与大额预算账目蒸发（修正 `ADR-0010` §3）**：无锚定自由选池下圈定 `3 ~ 8` 场时，槽位① `100%` 静默丢弃 `M - 1` 场仅买 1 场单关，与满场槽位②/③形成错位对比；`profitProb` 将净赚 `¥0.00` 的平手退本支计入“真赚钱率”（平均虚高 `14.45` 个百分点）；输入 `¥5,000` 等大额预算时，槽位①/②受内部 `500 / 999` 注硬锁截断且 `savedCash` 报 `0`，导致数千元预算在账面蒸发。
4. **主观倾向与信心滑块覆盖主看板客观基准**：开启「偏主队 / 防爆冷」或拖动 `±15%` 滑块后，系统用主观拉偏概率直接覆写看板主指标 `expectedValueRate` 与 `realProfitProb`，将 `-20.6%` 负期望串关渲染为 `+5.0%` 正收益，造成自我印证偏差。
5. **国内竞彩两大高频实战刚需缺失**：缺少体彩终端原生支持的 **「胆拖过关（定胆）」** 缩水机制；当用户单选 1 场非单关赛事（占竞彩 85%+ 场次）时，缺少自动扫描全盘 **「过桥配菜场」**（最低抽水稳胆或晚场可单关对冲搭子）凑 `2串1` 的能力。
6. **线下实体店打票摩擦与时间差安全余量不足**：同义双选比价仅算连续实数调和赔率，忽视 `¥10 ~ ¥30` 小预算下 `¥2` 整数注凑整导致的实际保底倒输；早晚场对冲 `110 分钟` 阈值未覆盖现代足球超长伤停补时与店面提前停售窗口；多张相近倍数零碎票缺乏合票压缩选项易引发店面变赔滑点。

## Decision

1. **三模奖金优化预算守恒、显式保本门槛升级与 `M串N` 联合状态保底**：
   - 默认严格以用户当前总投入为预算上限执行整数分配（零静默扩仓），修复器逻辑倍数上限统一对齐 `999`（终端打印层按 `99` 倍分张核算）；仅当用户显式触发「一键加至最低保本门槛」时才将预算提升至 `breakevenUpgradeCost`。
   - 对非互斥 `M串N` 多串过关按联合命中状态矩阵优化最差命中场景回血；当 `underwaterCount > 0` 时动态输出诚实减损定性，严禁展示“全选项均衡稳赚”或“彻底消灭假中奖”文案。
2. **时间戳实证滞后校验、全整数让球线闭合与国内主盘温和去水**：
   - 废除无视时间戳的单向泊松拉高截断；子盘仅在官方 `updateTime` 真实滞后主盘 `>= 30 分钟` 且跨盘同义/包含事件给出一致正偏离时保留滞后权重；
   - 主让球跨分割去水对齐推广至任意非零整数让球线 `goalLine`（含 `±1, ±2, ±3`），主盘采用契合国内竞彩返还曲线的温和幂次/等比混合去水，高抽水子盘混串（综合返还率 `< 72%`）统一触发抽水预警。
3. **满场公平对比、双口径净赚/保本拆分与预算守恒闭环**：
   - `3+1 精算配单` 槽位①默认锁定用户所选全部合法场次求最优保本解，低关数高胜率对比仅作底部文字参考提示；大额预算支持按最优配比线性扩仓至目标预算并严格保证 `totalCost + savedCash === cleanBudget`（或显式说明最小起投门槛）；
   - 全量透出 `strictNetGainProb`（`netProfit > 0`）与 `breakEvenProb`（`netProfit === 0`）双口径指标。
4. **素颜客观基准锁死与主观推演双轨并列**：
   - 无论 `stance` 或 `subjectiveDeltaPct` 如何调节，主看板与配单卡核心大字恒定展示基于客观校准分布计算的客观期望与客观严格净赚率；非客观状态下并列返回主观推演对照指标。
5. **原生胆拖定胆、全盘过桥配菜寻优与实体店防坑三小件下沉深模块**：
   - 在服务端精算工作区统一支持自由过关 `bankerMatchIds` 定胆展开、单场非单关 Top 2 过桥配菜场寻优（最低抽水稳胆 + `>= 135 分钟` 晚场单关对冲搭子）、基于当前预算的 `¥2` 整数注同义比价校验、`135 分钟` 早晚场安全对冲门禁以及可选相近倍数合票压缩。

## Consequences

- **正面收益**：彻底消除三模优化乱涨本金、千元分倍截断失真、伪 `+EV` 假阳性、静默删比赛与主观美颜自欺五大隐患；补齐国内竞彩最核心的「胆拖缩水」与「凑 2 串 1 找配菜」实战闭环，且保持客户端零算术泄露与单次工作区评估 `< 15ms`。
- **维护约束**：所有新增交互均嵌入既有 `1-2-3` 三步双视口骨架内，严守 `390px` 移动端超管最挤态零溢出与 `CODING_STANDARDS.md` 诚实性门禁。
