# 0010. 分割一致最小相对熵（KL/IPF）闭合校准、精确整数规划配单与真实实盘 OOS 门禁架构

Date: 2026-11-20

## Status

Accepted（基于跨语言红队盲审与 112+ 场中国体彩真实完场 OOS 数据，修正并深化 `ADR-0009`）

## Context

在独立红队使用 Python（`scipy.optimize` / `milp`）与中国体彩官方完场实盘样本外（OOS）盲测集对 `Spec 0008 / ADR-0009` 进行交叉核验后，查明五处核心理论与工程偏差：

1. **主让球盘 `Shin` 分割非不变性悖论与刚性泊松反噬**：中国体彩在 `让球(±1)` 中将两个冷门选项（如 `平 + 客胜`）合并为单一低赔项（`让负`）。对 `HAD` 与 `HHAD` 孤立运行非线性 `Shin` 去水会产生高达 `~8%` 的跨分割概率矛盾；再用仅 3 个自由度的刚性泊松网格强行折中，导致 112 场真实体彩 OOS 上闭合模型的 Brier 较单池 `Shin` 显著恶化（$p = 0.0321$），且其拟合残差在 `75%+` 的实盘盘面上误触发伪错价信号。
2. **大复式有损商空间压缩与静默砍单**：当跨场商状态数超过 `16,384` 时，将中间态概率对半分配至极值态，导致负期望串关出现高达 `+52.84` 个百分点的期望值幻觉；手动全包大复式超过 `512 / 2048` 注时静默截断且仍允许结账（`canCheckout: true`）。
3. **启发式剪枝欠优与未加权赔率劫持**：5~8 场盘面上，`稳健保本` 的单场翻转启发式较精确 0-1 背包整数最优解损失 `7.9% ~ 30.1%` 赚钱率；`期望效用` 误将实盘抽水损耗最低（`-7.74%`）的 `<= 1.45` 大热归因为“高抽水累赘腿”；`容错缩水` 目标函数混入未乘概率的裸赔付比 `0.2 * (missOneReturn / totalC)`，诱发 8 场全抓冷门的归零灾难。
4. **彩民知情权与凯利仓位红线失守**：将 `-31%` 负期望串关冠以「零风险多赚」诱导建仓、将负期望相对浅抽水串成共振串、双端硬编码 `0 假中奖倒贴`、配单卡片隐去真实 `数学期望 EV%`，以及对负期望注单给出违背凯利准则（最优 `0%`）的 `12%` 重仓建议。
5. **同源合成样本自证（Inverse Crime）**：原 96 场基准夹具系同构模型前向合成，且对非序数池（`HAFU`、`CRS`）误用一维 `RPS`。

## Decision

1. **零近似线性期望与超限显式阻断**：
   - 任何注单组合的 `expectedReturn` 与 `expectedValueRate` 恒由单张实票精确命中率线性求和 $\sum_k m_k u_k \prod_{g \in \text{legs}(k)} \mathbb{P}_g$ 直接计算（零状态空间近似误差）；商空间超限时采用保概率与条件均值的相邻赔付分位归并，且单次拆票超过 `2,048` 注或总金额超过 `¥20,000` 时显式返回 `canCheckout: false` 及真实注数阻断原因，严禁静默砍单。
2. **分割一致去水 + 扩展 `{0..14}²` 先验 + 最小相对熵（KL / IPF）闭合投影**：
   - 在 `{0..14}²` 比分网格上融合全量 9 项 `HAFU` 构建光滑先验分布 $Q$（消除深盘右尾截断与 `HAD+HAFU` 闷平失明）；
   - 当 `|goalLine| == 1` 且 `HAD`、`HHAD` 同开时，先在主分割上消除捆绑冷门带来的 `Shin` 分割撕裂并用 `HHAD` 条件比值细分净胜球，对长尾 `CRS / HAFU` 施加向先验 $Q$ 的经验贝叶斯平滑，最后经带权最小相对熵投影（SMART / IPF）收敛至严格闭合的物理原子分布 $P^*$（单场 `< 0.5ms`）。
3. **精确 0-1 背包与线性/整数规划重构 `3+1` 配单**：
   - **`max-profit-prob`（稳健保本）**：采用 `Float64Array` 精确 0-1 背包动态规划求解全局零假中奖最大真赚钱率（客观模式下跨合法 `1~M` 关全局择优，雷达选队锚定模式下满场精确求解并附低关数保本率对比）；
   - **`max-ev-utility`（期望效用）**：最大化真实期望对数财富效用，精简过关场次时严格按单腿真实期望返还 $O_i p_i$ 剔除高抽水拖累腿，移除硬编码护盾加分偏置；
   - **`max-cvar-wheel`（容错缩水）**：移除未加权赔率爆炸项，锚定高概率主胆并通过线性规划热启动 + 整数精调最大化条件概率加权错 1 场 CVaR 与最差错 1 场底线，修正标准 $C(v, k, t)$（$v \ge k \ge t$）记号并披露 `错 >= 2 场击穿率`；
   - **`alpha-radar`（错价雷达）**：严格执行纯正期望硬门禁（收缩校准后单腿 $O \cdot p_{\text{shrunk}} \ge 1.01$ 且整单 `EV > 0%`），严禁负期望二次串关，无真 `+EV` 时 100% 诚实空仓；`同义错价替换` 仅作单场微标与审单台已选低效项平替提醒，永久禁用「零风险」措辞。
4. **全量透出真实 `EV%`、动态假中奖披露与凯利娱乐仓位上限**：
   - `ArchetypePlan` 与双端卡片直接展示校准 `数学期望 EV%` 及动态真实 `underwaterCount`；当 `EV <= 0` 时凯利最优仓位为 `0%`，界面仅给出 `<= 1% ~ 2%` 娱乐预算护栏提示。
5. **冻结中国体彩官网真实完场 OOS 盲测门禁**：
   - 原合成数据改名 `syntheticCoherenceFixture.json` 仅作公理测试；采集 `240+` 场中国体彩官网完场五池实盘数据冻结为 `realSportteryOosMatches.json`，仅在序数池计算 `RPS`，全池以 `Log-Loss` + `Brier` + 万次配对 Bootstrap 置信区间与无双标账本回放作为唯一科学基准。

## Consequences

- **正面收益**：在真实体彩完场 OOS 集上实现五大玩法校准度相对等比去水全线同向提升（Log-Loss $p < 0.005$）且不劣于单池 `Shin`；彻底消灭大复式期望幻觉、静默砍单、负期望诱导建仓与 8 场冷门归零漏洞；5~8 场配单逼近/达到全局整数规划最优且全工作区保持 `< 15ms` 响应。
- **维护约束**：所有后续概率或配单算法演进均须在不修改 `realSportteryOosMatches.json` 冻结样本的前提下通过万次配对 Bootstrap 与跨语言对账门禁。
