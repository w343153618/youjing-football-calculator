# 采用 100% 手机原生交互优先架构与 Capacitor 跨端封装

由于核心使用场景明确聚焦于手机 APP 端（看盘、选队配单、临场对冲与线下体彩店出示打票），桌面网页端仅作附带调试预览，我们决定以纯正手机竖屏高密度交互（底部 4-Tab 分流、微缩精算结论胶囊、单手拇指半屏抽屉 Bottom Sheet 与横向流派滑卡）作为唯一主设计规范，并采用 React + TypeScript + Capacitor（兼顾独立全屏 PWA）架构封装。这样既能一键编译生成 Android `.apk` 与 iOS `.ipa` 原生安装包，又允许 iPhone 用户在无付费开发者签名时通过主屏幕全屏独立模式永不过期运行；底层水位同步利用体彩公开接口（`webapi.sporttery.cn`）跨域直连能力配合本地 IndexedDB 存储快照，户外蜂窝网络下无需依赖电脑即可独立运作。
