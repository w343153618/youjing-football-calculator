# 采用双端自适应独立排版（手机贴边触控 + 电脑宽屏三栏）与服务端实盘快照同步架构

针对「优竞体育内部专用」同时覆盖手机端浏览器/APP 与电脑端深度看盘的实际场景，我们采用双端差异化自适应架构：在手机端（`< 960px`）呈现 `100dvh` 贴边全屏原生级触控布局（底部弹簧四页签、手势阻尼抽屉、安全区适配），在电脑端（`>= 960px`）自动切换为三栏同屏宽屏精算工作台（左栏赛事雷达全盘矩阵、中栏五维审单与三模奖金优化、右栏五流派推荐与扫地僧小高排雷），并内置全套矢量图文精算说明书。线上 Web 端通过 `https://jisuanqi.yjty.io` 部署于新加坡腾讯云（Nginx 443 Let's Encrypt 证书反向代理至宿主机高端口 `127.0.0.1:18768`）。

> **架构演进说明（自 `v1.2.0` / `Spec 0002` 起更新）**：早期原型曾规划“浏览器端直连 `webapi.sporttery.cn` + 服务端兜底”；在核心精算全量上收服务端黑盒与 `AES-256-GCM` 密文网关落地后，实盘水位同步已统一收敛为 **100% 服务端加密代理三层回退机制**（客户端请求加密接口 `POST /api/quant/sync` → 服务端请求体彩官网计算器接口并刷新 120s 内存热缓存 → 失败回退磁盘 `data/sporttery-snapshot.json` → 再失败回退内置 `FALLBACK_MATCHES`），浏览器不再直接发起外部跨域请求。
