# 采用手机优先的独立 PWA 架构与双通道水位同步

虽然核心场景包含在手机端替代体彩官方移动页并在线下体彩店随时使用，我们决定采用手机优先、兼顾电脑大屏的独立 PWA（渐进式 Web 应用）而非原生 iOS/Android 客户端，并将所有历史水位快照与注单数据持久化在浏览器本地（IndexedDB）。这是因为个人自用工具无需上架应用商店，iOS 自签原生安装包存在 7 天证书过期痛点，而体彩公开计算器接口（`webapi.sporttery.cn`）原生允许跨域直连（`Access-Control-Allow-Origin: *`），使纯前端 PWA 在户外蜂窝网络下也能脱离电脑独立一键同步水位；同时保留轻量本地代理与文本导入作为接口跨域策略变更时的兜底通道。
