# 0009. Shin/Power 跨盘闭合 Dixon-Coles 概率底座与联合状态空间 3+1 帕累托配单架构

Date: 2026-11-19

## Status

Accepted（扩展并深化 `ADR-0007` 状态空间架构；其中刚性四参数泊松直接覆写、启发式剪枝与相对错价门禁已由 `ADR-0010` 演进修正）

## Context

对 `v2.2.0 + Spec 0007` 精算内核进行全量数学审计与文献源码交叉核验后，暴露出原有概率底座与「五流派配单」在客观数学层面的系统性局限：

1. **单池等比例去水与跨盘概率撕裂**：原内核使用简单等比归一化（`Multiplicative`），在抽水高达 `20% ~ 37%` 的半全场（`HAFU`）与 31 项比分（`CRS`）池中忽略了庄家冷热偏差（Favorite-Longshot Bias），使高赔冷门真实隐含概率被系统性高估 `1.8 ~ 4.0` 倍；同时五大奖池孤立去水导致同场 `胜胜+平胜+负胜 != 主胜`、`总进球0球 != 比分0:0`，`xG` 依赖线性经验系数，同场双单关（`HAD + HHAD`）甚至采用脱离水位的写死净胜球权重，`Spec 0007` 亦只能用「`±1` 看让平、深盘切比分」的分段规则修补一球卡盘率。
2. **非互斥实票概率直接相加与主盾倒挂**：在多串容错、三模奖金优化与跨玩法多票方案中，原内核直接将重叠命中的实票概率相加并截断于 `92%`，虚标胜率与赚钱率；分倍器中写死 `shieldOnly: 0.04` 经验常数，在 4 场以上串关时引发回本护盾反抢超半数预算的“主盾倒挂”；倾向调节直接单边乘 `1.08 / 1.12` 破坏概率归一。
3. **凑数五流派违背功利客观准则**：原「进球结构流」在无边际优势时硬推总进球串关，原「错价刺客流」按固定剧本硬抓 `1:0 / 平胜 / 让平` 而未做跨盘定价偏离检验，在全盘定价严密时劝买负期望高抽水注单。

## Decision

1. **零历史库「单池 Shin/Power 去水 + 四参数 Dixon-Coles 二项半场拆分」统一闭合概率核**：
   - 单池去水升级为 **Shin 方法**（极端数值边界回退 **Power 幂次法**），挤压长尾冷门保护性暗扣水分；
   - 以同场在售低抽水主盘（`HAD + HHAD + TTG` 按返还率反方差加权，`HAFU` 正则拟合半场进球占比 $\hat{\theta} \in [0.38, 0.46]$，停售时取 $\theta_0 = 0.43$）实时超定反演四参数 $(\hat{\lambda}_H, \hat{\lambda}_A, \hat{\rho}, \hat{\theta})$（单场耗时 `< 0.5ms`），由同一张半全场×全场比分联合分布导出五大玩法 **100% 闭合**的全局 `fairProb`、精确双方 `xG`、任意让球线统一的**一球卡盘率**与比赛节奏相关性（仅在单场在售奖池不足 2 个时回退单池 `Shin/Power`）；
   - 看球倾向与主观胜率信心微调统一在底层状态空间做保序倾斜并严格重归一化至总和 `1.000000`。
2. **商状态压缩联合状态空间 $\widetilde{\Omega}$ 与「物理实票 `tickets` / 互斥赛果 `combos`」双层解耦**：
   - 将单场 139 个物理相容的 `(半场赛果, 全场比分)` 原子格点按当场候选实票腿的命中签名等价类精确折叠为极小互斥商状态空间 $\widetilde{\Omega}_m$，在乘积空间 $\widetilde{\Omega} = \prod_m \widetilde{\Omega}_m$ 上对手动选单、三模奖金优化与精算配单统一执行精确积分；
   - 审单报告严格拆分 `tickets`（体彩店逐张打印的物理实票行）与 `combos`（$\widetilde{\Omega}$ 上严格互斥的中奖结果场景，总概率恒等于 `anyWinProb <= 1`），彻底根除重叠注单概率虚标与同场双单关经验权重。
3. **「3 大正交帕累托极值 + 1 个宁缺毋滥真错价雷达」精算配单体系**：
   - 废除凑数五流派，重塑为数学目标严格正交的四席（对外保留向后兼容字段与旧键值映射）：
     - **`max-profit-prob`（稳健保本）**：覆盖态零假中奖硬约束下最大化真赚钱率；
     - **`max-ev-utility`（期望效用）**：保本护盾严格锁死最小整数倍 $\lceil C / u_{\text{shield}} \rceil$，纯客观模式下主动裁剪 `<= 1.45` 蚊子肉累赘腿（雷达选队锚定模式下保留场次并高亮预警），集中火力最大化风险调整期望效用；
     - **`max-cvar-wheel`（容错缩水）**：在最多 `10 张` 独立实票上限内融合预编译组合覆盖旋转矩阵 $C(v, k, t)$ 与官方 `M串N`，最大化错 1~2 场尾部条件保底回血（`CVaR`）；
     - **`alpha-radar`（错价雷达）**：对细分盘口施加向单池 `Shin` 的经验贝叶斯收缩防长尾高估，仅在期望返还显著跑赢同场最低抽水主盘 `>= +3.0%`（或存在同义高水差价）时轻仓激活（诚实区分标注「绝对 `+EV`」与「跨盘低抽水洼地」）；若全盘无真洼地，严格输出 **`¥0` 空仓省钱态**并禁用套用，绝不硬凑垃圾单。

## Consequences

- **正面收益**：同场五池概率实现机器精度自洽，彻底消除跨盘概率撕裂、重叠注单胜率虚标与 4+ 场主盾倒挂；旋转矩阵缩水较全包多串最高可省 `50% ~ 70%` 注数锁定错场回血；无真错价时诚实建议空仓，严守功利客观底线；单次 8 场工作区精算总耗时稳定在 `< 15ms`。
- **演进与测试约束**：全端导航与说明书由「五流派」焕新为「精算配单」；既有测试中耦合旧等比去水数值、`Spec 0007` 分段 `CRS` 卡盘比值或固定 5 个非空流派长度的断言须按本架构契约同步升级，并由新增的 4 层自动化科学基准测试（完场实盘 `RPS/Brier/ECE`、公理不变量、10,000 次蒙特卡洛帕累托前沿检验、双轨账本消融回放）长期锁死。
