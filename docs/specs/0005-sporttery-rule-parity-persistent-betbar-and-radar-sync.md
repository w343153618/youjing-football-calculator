# Spec 0005 · 中国体彩法定选号规则对齐、全局常驻「过关+倍数」总控栏与五流派雷达选队同步（v2.1.0）

> 源自 `grill-with-docs` 需求深烤与对中国体彩官方计算器（`m.sporttery.cn/mjc/jsq/zqspf/` & `zqhhgg/`）源码级规则核验。同步受 `GLOSSARY.md` 与 `docs/adr/0007` 约束。

## 1. 中国体彩法定选号与出票规则 100% 同步（修复原有乱选 Bug）

1. **同场单一玩法互斥铁律（Same-Match Single-Pool Exclusivity）**：
   - 同一场比赛在**同一玩法内**允许复式多选（如同时点选 `[0] 胜平负` 的 `胜 + 平`）。
   - **串关互斥**：一旦某场比赛已点选某一玩法（如 `科里蒂巴 vs 桑托斯` 已选 `[0] 胜 3.63`），在混合过关模式或存在任一未开单关选项时，同场的其他所有玩法（`[+1] 让球胜平负`、`比分`、`总进球`、`半全场`）立即进入**同场互斥锁止态**（视觉弱化角标提示，点击时拦截拒绝选中并弹出体彩规则提示：「同一场比赛只能选择一种玩法进行串关计算；如需改选其他玩法，请先取消本场已选项」）。
   - **双单关唯一例外**：仅在非混合过关（`胜平负` / `单关` 视图）下，当同场两个玩法（`HAD` 与 `HHAD`）及当前全单所有已选比赛均已开放单关（`single === true`）时，允许同时勾选同场两个单关玩法，但系统立即**自动将过关方式强制锁死为【单关】**（禁用 `2关~8关` 所有串关选项）并弹出明确提示，完全对齐体彩官方计算器逻辑。
2. **盘口未开售 / 停售状态置灰禁选**：
   - 完整解析官方接口各玩法的开售状态与空赔率；若某场未开 `[0]` 胜平负（或某玩法停售），对应让球线显示 `[未]`、按钮置灰不可点击；已开单关的具体玩法行（`[0]` 或 `[±1]`）单独高亮官方同款「单」字微标。
3. **31 项官方全量比分选项（含 `胜其它 / 平其它 / 负其它`）**：
   - 修复原先比分（`CRS`）仅解析 11 个比分导致漏项及返还率失真的问题，完整支持中国体彩全部 **31 个法定比分选项**（主胜 13 项含 `胜其它`、平 5 项含 `平其它`、客胜 13 项含 `负其它`）。
4. **场次上限与玩法最高过关关数硬约束**：
   - **串关最多 8 场**：在混合过关或含非单关选项时，已满 8 场后再点第 9 场比赛直接拦截并提示「过关数量不能超过 8 场赛事」；仅当全部所选场次均开单关且处于非混串单关模式时允许超 8 场并强制锁死【单关】。
   - **各玩法最高串关关数（`limitLen`）**：
     - `胜平负 (HAD)` / `让球胜平负 (HHAD)`：最高 **8 关**
     - `总进球 (TTG)`：最高 **6 关**
     - `比分 (CRS)` / `半全场 (HAFU)`：最高 **4 关**
     - 当已选场次中包含 `比分/半全场` 且总场数 `> 4`（或含 `总进球` 且总场数 `> 6`）时，允许保留这 `5~8` 场比赛，但在「过关选择」中自动禁用超出上限的关数（例如 6 场含比分时，最高只允许选 `2关 / 3关 / 4关` 自由过关拆票，禁止 `5关 / 6关`），并给出清晰规则说明。
5. **单关资格校验与未成单归零规则**：
   - 「过关选择」中的【单关】仅在**当前已选全部选项均开放单关（`isAllSingle === true`）**时可勾选；哪怕混入 1 场未开单关的选项，【单关】立即禁用。
   - 当仅选了 1 场比赛且该玩法未开单关时，严格对齐官方计算器：`可出票状态 = false`，`投注金额 = ¥0`，`理论最高奖金 = ¥0.00`，底栏明确提示「未开单关 · 还差 1 场凑 2串1」，并在审单台提供一键切换本场半全场/比分的「合成单关」救场建议。
6. **单票倍数与单次订单金额法定护栏**：
   - 九宫格键盘与步进器支持 `1 ~ 999` 倍调节；超过体彩终端机单张实票 `99` 倍上限时自动计算拆票张数；单次订单总金额超过 `¥6,000` 触发理性购彩提示，超过体彩单次订单硬上限 `¥20,000` 时标红预警拦截。
7. **登录与同步水位默认洁净空选单（修复默认勾选 4 个半全场问题）**：
   - 账号登录成功握手及手动点击「同步水位」（当当前无已选项时）默认保持洁净空选单（`initialPicks = []`，`已选 0 场 · ¥0`），与体彩官方计算器初始状态一致，绝不自动预勾选某场比赛的 4 个半全场选项（教学演示仅在用户主动点击顶部 `演:假中奖` 等标签时载入）。

## 2. 全局常驻「过关选择 + 倍数」总控底栏（参考 `m.sporttery.cn/mjc/jsq/zqspf/`）

1. **全视口、全页面、全滚动位置 100% 始终可见**：
   - **桌面端（`>= 960px` 三栏宽屏）**：在三栏容器下方固定挂载全局总控底栏（不随左/中/右任一分栏滚动而消失），同屏常驻：**已选场数（可点开查看/一键清空）**、**过关选择按钮**、**倍数步进与数字键盘入口**、**注数与应付总本金**、**真实保底奖金 ～ 理论最高奖金 + 真赚钱率/假中奖预警**、**查看实票核对单按钮**。
   - **手机端与安卓伴侣端（`< 960px` 四页签架构）**：总控栏固定悬浮在底部导航栏正上方：
     - 在 **【赛事雷达】** 与 **【审单锁利】** 页：默认呈现**完整双行操控态**（第一行：`已选 N 场` + `过关选择` + `清空`；第二行：`倍数按钮/步进` + `投注金额 & 保底~最高真奖金` + `审单/看方案`）；
     - 在 **【五流派】** 与 **【情报账本】** 页：自动收拢为 **常驻紧凑状态胶囊栏**（依然实时显示 `已选N场 · 过关方式 · N倍 · ¥本金`，点击任意位置即刻原地展开过关选择面板或九宫格倍数键盘），兼顾 100% 全局可见性与小屏阅读空间。
2. **官方级「过关选择」交互浮层（自由过关多选 + M串N 多串容错）**：
   - **自由过关（8 格矩阵，支持多选叠加）**：`单关`、`2关(2串1)`、`3关(3串1)`、`4关(4串1)`、`5关(5串1)`、`6关(6串1)`、`7关(7串1)`、`8关(8串1)`，实时按场数、单关资格及 4/6/8 关上限启停，并标注不可选原因。
   - **多串容错快选（官方标准 `M串N` 表）**：选满 `3~8` 场时动态展示官方标准容错组合（`3串3, 3串4`；`4串4, 4串5, 4串6, 4串11`；`5串5, 5串6, 5串10, 5串16, 5串20, 5串26`；`6串6~6串57`；`7串7~7串120`；`8串8~8串247`），一键切换并由服务端互斥赛果空间精算「错1场/错2场/全红」真实盈亏分布。
3. **官方同款九宫格倍数键盘 + 智能分倍双态无冲突切换**：
   - 手动等倍态：支持 `− / +` 微调，点击 `N倍` 呼出九宫格数字键盘（`0~9 / 删除 / 确认` + `1 / 5 / 10 / 20 / 50 / 99倍` 快捷档）。
   - 智能分倍态：当用户启用【平均优化 / 博热保本 / 博冷高弹】或套用【五流派】不等倍方案时，倍数槽自动切换展示 `⚖️ 智能分倍中 (总¥X)`，提供 `×2倍扩仓` 与 `还原等倍` 快捷钮，彻底消除等倍与分倍的认知打架。

## 3. 五流派智能推荐「一键匹配赛事雷达已选球队」联动按钮

1. 在【五流派智能推荐】顶部（对齐扫地僧小高排雷舱的显眼入口）新增 **「🎯 一键匹配赛事雷达已选球队（已选 N 场）」** 按钮。
2. 点击该按钮后：
   - 自动将左栏【赛事雷达】当前已选的 `1~8` 场比赛同步至五流派目标对决池（`targetIds`）；
   - 开启 **雷达选队方向锚定（`anchorPicks`）**：服务端 `generateFiveArchetypes` 读取用户在赛事雷达中对每场比赛亲手点选的球队/盘口倾向（例如用户选了受让冷门方或特定进球/半全场方向），围绕该方向生成铁盾保本、博胆护盾、容错防爆、进球结构与错价刺客五大方案，绝不违背用户意向强行改推反方向热门；
   - 若用户随后在左栏【赛事雷达】增删修改了选队，按钮实时高亮提示 `🔄 雷达选单已更新（N场），点此同步`，同时支持一键切回「纯盘面客观重选」。
