# Spec 0014 · 竞彩开休市静默门禁、真实协议栈指纹持久化与多源无规律防封同步体系

> 同步归档自 GitHub Spec Issue，供后续演进与 `matt-pocock` 流程按 `AGENTS.md` 上下文导航指针永久检索，防止回退至高频单源裸连轮询。

## Problem Statement

成员与店主在日常使用「优竞体育内部专用」竞彩足球工作台看盘、执行「精算配单」、导出「店主出票口令」及进行「自动赛果对奖」时，现有数据同步机制在长期抗风控稳定性上存在四项突出痛点：

1. **双路高频直连与裸协议特征极易触发风控拦截**：原服务端存在路由层缓存刷新与后台历史采集两套各自独立触发的外网请求路径，不仅轮询间隔密集（数十秒至两三分钟一次，冷启动历史回补甚至每隔数秒连续请求），而且使用默认脚本级网络握手且完全绑定单一域名；在境外服务器网络出口环境下，极易因协议指纹异常或高频规律请求被目标站点限流、连接重置或封禁 IP。
2. **竞彩休市与无人看盘时段仍在昼夜空转请求**：中国体彩竞彩足球每日早间 `11:00`（北京时间）前及晚间「官方停售红线」关闭后原本就处于休市无调水状态，在凌晨与休市期继续发起外网轮询既无业务价值，又直接暴露全天候自动化机器作息特征。
3. **单点数据源无备胎切换，且第三方备份盘与实票安全缺乏衔接**：一旦单一官方接口出现跨境网络抖动、超时或返回“假 `200`”空壳维护页，系统只能被动回退旧缓存而无法自动切换至其他公开免费国内竞彩站点继续同步；同时若简单拿慢半拍且不含终端实时开售签名的第三方网页赔率直接替代官方盘，又可能造成旧「水位」倒盖新「水位」或打出错价实票。
4. **手动连点刷新缺乏全局限流保护**：前端手动刷新操作若直接穿透后台节奏发外网请求，多人看盘或连点即可击穿防封限流。

## Core Rules & Contracts (不可回退防封基线)

1. **「开休市静默门禁」与按需唤醒**：
   - 每日北京时间 `00:00 ～ 11:00` 强制处于物理静默态（`0` 次外网请求），前台直接秒读休市前最后有效「水位快照」并提示休市状态；
   - `11:00` 后叠加毫秒级随机苏醒偏移（`73s ～ 530s`），在存在活跃看盘会话（近 `60 分钟` 内有访问）期间启用无规律自动同步；若开市期间超过 `60 分钟` 无人访问则转入省流待机（仅保留开市首帧与傍晚慢检，新会话到达且距上次同步超阈值时后台单飞补拉一次）；
   - 晚间检测到官方停售状态开启（`offLineSaleStatus !== 1`）或已过常规停售兜底点（周中 `22:10` / 周末 `23:10`）且无未截止在售场次时进入夜间休市态（仅当双轨账本存在待结算注单时允许低频核对完场赛果，结清或过凌晨 `01:30` 后整晚 `0` 请求休眠）。
2. **无规律反整刻钟随机间隔（严禁整 15/20 分钟或整刻钟对齐）**：
   - 活跃期同步间隔在 `[853_000ms, 1_307_000ms]`（约 `14分13秒 ～ 21分47秒`）连续区间由双独立随机数叠加毫秒尾数采样；
   - 若计算出的目标触发时刻落入 `:00 / :15 / :30 / :45` 整刻钟前后 `±35 秒` 区间，自动顺延非对称随机毫秒偏移（`41s ～ 119s`）。
3. **全局唯一限流出口（收口手动刷新与历史回补）**：
   - 路由层加载、手动刷新、后台在售轮询及 24 个月历史回补统一经单一单飞防封网关调度（全局并发 `= 1`，每域名 60 秒滑动窗口硬限流 + `ETag / If-Modified-Since` 条件缓存）；
   - 手动刷新在休市期 `0` 外网请求，开市期距上次成功外网同步 `< 5 分钟` 直接秒回内存最新快照；冷启动历史回补仅在开市期按低频配额慢速捎带执行，休市期一律暂停。
4. **真实浏览器协议栈握手、同域 30 天固定身份与假 `200` 识破**：
   - 采集层使用真实浏览器 TLS（JA3/JA4）与 HTTP/2 协议栈客户端及完整 `zh-CN` 关联头，严禁裸脚本客户端握手；
   - 本地持久化库按域名绑定固定浏览器档案与访客会话 Cookie（连续 `30 天` 内保持同一身份，严禁逐次随机换 `User-Agent`，仅受阻率超阈值时轮换），内置假 `200` 空壳/挑战页识破器。
5. **多源健康池真随机轮转、「多源备份同步盘」与实票前官方核对**：
   - 内置多个独立公开免登录国内竞彩源（含中国体彩双通道及公开竞彩备份站点），每次从健康未冷却站点加权随机抽取 1 站；单次失败或命中假 `200` 时 **`0` 重试秒切下一健康站**并写入阶梯冷却（`30 分钟 → 2 小时 → 6 小时`）；
   - 跨源按「标准周赛事编号 + 归一化主客队名」对齐并执行分池时间戳单调防倒退锁（慢盘不盖新盘，缺冷门子池时保留同场上次有效子池并标明）；
   - 第三方备份源盘面诚实标记为「多源备份同步盘」（完整支持浏览、「精算配单」、「三模奖金优化」与零成本「模拟观察单」）；当成员在备份盘下导出「店主出票口令」或封存「实买单」时，自动触发受限流保护的官方通道实时报价与单/串售权核对，核对一致无缝放行，变价提示重审，官方不可达则诚实保留模拟观察单防打错票。
