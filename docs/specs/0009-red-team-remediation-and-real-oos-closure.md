## Problem Statement

在独立红队采用跨语言参考实现（Python `scipy.optimize` / `milp` + `decimal.Decimal`）及中国体彩官网完场实盘样本外（OOS）数据集对 `Spec 0008` 内核开展盲审后，确认存在 `D-01` 至 `D-10` 共 10 项影响精算精确性、统计学有效性及彩民知情公平性的缺陷：

1. **大复式期望值严重失真与静默砍单（`D-01`, `D-02`）**：当跨场商状态数超过 `16,384` 时，有损压缩把中间态概率对半塞入最高赔与最低赔状态，将负期望串关（`-33.80%`）扭曲为暴利正期望（`+19.04%`）；当手动选单组合数超过 `512 / 2048` 注时，系统在未阻断结账、未提示截断的情况下静默丢弃超额注单，使 8 场全包必中单命中率跌至 `23.90%` 且仍显示可出票。
2. **主让球盘去水分割矛盾与刚性泊松反噬实盘校准度（`D-03`, `D-10`）**：`胜平负` 与 `让球(±1)` 孤立执行非线性 `Shin` 去水会产生跨分割概率撕裂，再用 3 自由度 `{0..10}²` 刚性泊松网格强行折中，不仅在超深盘截断右尾、在仅开 `HAD+HAFU` 时对半全场闷平失明，更在 112 场中国体彩真实完场 OOS 盲测中使五大玩法 Brier 相对单池 `Shin` 统计显著恶化（$p = 0.0321$），且其拟合残差在 `75%+` 的实盘盘面上误触发伪错价信号。
3. **启发式配单偏离全局整数最优与未加权赔率爆炸（`D-05`, `D-06`, `D-07`, `D-10`）**：5~8 场盘面上，`稳健保本` 的 4 票单场翻转启发式较精确 0-1 背包整数最优解损失 `7.9% ~ 30.1%` 真赚钱率；`期望效用` 误将实盘暗扣最低（`-7.74%`）的 `<= 1.45` 大热判定为“高抽水累赘腿”并含硬编码护盾加分偏置；`容错缩水` 目标函数混入未乘发生概率的裸赔付比 `0.2 * (missOneReturn / totalC)`，诱使 8 场盘全抓 `~24%` 冷门（14 期真实 8 场回测 `-100%` 归零），且部分旋转矩阵 $C(v,k,t)$ 参数顺序与阈值标注失准。
4. **诱导性文案、隐去真实 `EV%`、写死 `0 假中奖倒贴` 与违背凯利的仓位建议（`D-04`, `D-05`, `D-07`）**：`同义错价替换` 在无正期望优势时主动激活 `错价雷达` 并输出「零风险多赚」文案，甚至将负期望相对浅抽水选项串成 `2~3串1` 复利放大亏损；双端配单卡片第 2 格硬编码 `0 假中奖倒贴`（掩盖容错单 `57.1%` 存在局部回血低于本金的事实），第 3 格仅展示奖池表面抽水而隐去真实 `期望回报率 (EV%)`；审单洞察对负期望注单给出 `12%` 重仓建议（50 注内腰斩率 `77.9%`）。
5. **缓存签名碰撞、极端大单延迟越界与合成样本自证（`D-03`, `D-08`, `D-09`）**：单场校准缓存仅取首中尾 3 个选项赔率导致改赔漏检，`8串247 + 奖金优化` 评估延迟超 `< 15ms` 门禁；原 96 场基准夹具实为同构模型合成数据，且基准脚本对非序数池误算 1D `RPS`、对 31 项比分误用等宽 10 桶 ECE、在蒙特卡洛与账本回放中存在筒仓过滤与止损双标。

## Solution

在不改动体彩法定计奖与安全鉴权红线的前提下，对精算校准、商空间评估、整数规划配单、双端诚实披露与科学验证套件实施五位一体彻底闭环：

1. **零近似线性期望 + `2,048` 注显式超限阻断 + 全量缓存签名与矩阵复用**：任何注单组合的数学期望永远由单票精确概率线性求和零误差导出；超 `2,048` 注或超 `¥20,000` 显式阻断结账并展示真实总注数；全选项签名消除缓存碰撞，共享商空间转移矩阵将 `8串247` 全工作区耗时稳定压入 `< 15ms`。
2. **分割一致去水 + 扩展 `{0..14}²` 先验 + 最小相对熵（KL / IPF）闭合校准**：消除 `HAD` 与 `HHAD(±1)` 跨分割去水撕裂，在融合全量 9 项 `HAFU` 的 `{0..14}²` 先验网格上经经验贝叶斯长尾平滑与最小相对熵比例投影导出严格闭合的五池概率，确保在中国体彩真实完场 OOS 数据集上五大玩法校准度全面优于等比去水且不劣于单池 `Shin`。
3. **精确 0-1 背包与线性/整数规划驱动 `3+1 精算配单`**：
   - **① 稳健保本**：采用精确 0-1 背包动态规划求解全局零假中奖最大真赚钱率（纯客观模式下跨合法 `1~M` 关全局择优，雷达选队锚定模式下对已锚定场次精确求解并附低关数保本率提示）；
   - **② 期望效用**：采用真实期望对数财富效用优化，精简场次时严格按单腿校准期望返还 $O_i p_i$ 剔除**高抽水拖累腿**；
   - **③ 容错缩水**：移除未加权赔率爆炸项，锚定高概率主胆并通过线性规划热启动 + 整数精调最大化条件概率加权错 1 场 CVaR 与保底回血，修正标准 $C(v,k,t)$ 记号并披露 `错 >= 2 场击穿率`；
   - **④ 错价雷达**：严格执行纯正期望硬门禁（收缩校准后单腿期望返还 $\ge 1.01$ 且成单总 `EV > 0%`），严禁负期望共振串，常规无套利盘面 100% 诚实空仓省钱。
4. **彩民知情权全量透明披露**：永久下线 `"零风险"` 措辞；双端配单卡片直接透出真实校准 `数学期望 EV%` 与动态真实假中奖组合数；负期望注单严格按凯利准则将娱乐参考仓位限制在 `<= 2%`。
5. **冻结 240+ 场中国体彩官网真实完场 OOS 盲测基准**：分离合成公理夹具与真实完场 OOS 盲测集，采用严格恰当评分规则（`Log-Loss`、`Brier`、仅限序数池的 `RPS`）与 10,000 次配对 Bootstrap 置信区间、无筒仓蒙特卡洛检验及同规则净免损账本消融回放，并通过红队独立 Python/Node 全套验算门禁。

2. 作为内部成员，当我在赛事雷达手选全包大复式超过 `2,048` 注（如 8 场全包 `6,561` 注）或总金额超过 `¥20,000` 时，我希望系统明确阻断结账并如实显示真实总注数、真实总金额与拦截原因，以便绝不发生静默漏单或错误命中率。

## Implementation Decisions

1. **零近似线性期望与精确十进制舍入**：
   - 在联合状态空间积分器与全部审单报告出口中，`expectedReturn` 统一按 $\sum_{k=1}^K m_k u_k \prod_{g \in \text{legs}(k)} \mathbb{P}_g$ 直接计算，`expectedValueRate = (expectedReturn - totalCost) / totalCost`，不经由任何压缩态近似；
   - 当跨场商状态乘积超过精确枚举阈值（提升至 `32,768`）时，仅对同场命中态执行保持概率和与条件期望赔付不变的相邻赔付桶归并；对同场单玩法复式，额外用 $O(2^M)$ 场次命中子集动态规划精确锁定 `anyWinProb`；
   - 通用金额舍入辅助函数统一按十进制字符串拆解或整数放大执行四舍六入五成双，消除 IEEE-754 二进制浮点半值边界漂移。
2. **前置组合计数、`2,048` 注显式阻断与全选项缓存签名**：
   - 审单引擎在展开实票数组前先精确计算 `totalRawBetCount` 与 `totalCost`；若 `totalCost > 20000` 或 `totalRawBetCount > 2048`，直接返回 `canCheckout: false`、真实 `betCount`、真实 `totalCost` 与清晰阻断原因，禁止静默截断；
   - 单场校准 `WeakMap` 缓存签名完整编码五池 `selling`、`single`、`goalLine` 及全部选项 `key:odds`；
   - 工作区评估器在单次请求内对同一组基础选单与过关规格缓存商空间命中矩阵，供手动审单、三模奖金优化与当前生效报告直接复用分倍向量点积，确保 8 场 `8串247` 全工作区耗时 `< 15ms`。
3. **分割一致去水 + `{0..14}²` 先验 + 最小相对熵（KL / IPF）闭合校准**：
   - 先验层在 `{0..14}²` 全场比分网格与二项半场拆分上联合利用在售 `HAD`、`HHAD`、`TTG`、全量 9 项 `HAFU` 与 `CRS` 拟合光滑基底分布 $Q$（当仅 `HAD + HAFU` 在售时，直接利用 `HAFU` 9 项特别是 `dd` 半全场平平项识别进球尺度）；
   - 目标边际对齐层：当 `|goalLine| == 1` 且 `HAD` 与 `HHAD` 同开时，先融合未捆绑 `HAD` 的 `Shin` 主方向概率与具可加性的让球等比边际确定一致的胜/不败总概率，再用具跨事件可加性的 `HHAD` 等比条件比值拆分净胜 1 球与净胜 $\ge 2$ 球（规避体彩让平一球保护水下 `Shin` 对让球子项的过度扭曲），彻底消除跨分割去水冲突；对多分支高抽水池（`HAFU`、`CRS`）施加向先验 $Q$ 的经验贝叶斯收缩以滤除官方高赔整数跳档噪声；
   - 投影层：在物理相容的 `(半场赛果, 全场比分)` 原子空间上执行带池精度权重的对数线性最小相对熵投影（SMART）与主盘边际精锁迭代，输出严格归一、五池闭合误差 `< 10⁻¹²` 的全局 `fairProb`。
4. **精确整数规划重构 `3+1 精算配单` 与诚实披露契约**：
   - **`ArchetypePlan` 数据契约扩展**：新增 `expectedValueRate: number`、`underwaterCount: number`、`wipeoutMiss2Prob?: number`（容错缩水档专用），保留全部向后兼容字段；
   - **槽位①（`max-profit-prob`）**：实现基于 `Float64Array` 的精确 0-1 背包动态规划器（给定互斥候选票集合与总注数上限，精确求解满足 $\forall k \in S,\, m_k u_k \ge 2N$ 且 $\sum m_k = N$ 的最大概率子集）；纯客观模式下在目标池合法单关/`2串1`/至 `M串1` 中选取全局最高真赚钱率方案，雷达锚定模式下在锚定场次上求精确 0-1 背包最优并在 `M >= 4` 时附精选低关数保本率对比说明；
   - **槽位②（`max-ev-utility`）**：最大化真实期望对数财富效用 $\mathbb{E}[\ln(1 + \gamma \frac{R(\omega)-C}{\max(B, C)})]$（$\gamma = 0.65$），评估纯主攻与最小整数倍回本盾组合而无任何硬编码护盾加分；精简过关场次时按单腿校准期望返还 $O_i p_i$ 升序剔除高抽水拖累腿，同步更新说明书与词库解释；
   - **槽位③（`max-cvar-wheel`）**：移除未加权 `missOneReturn / totalC` 项；选腿锚定高胜率主胆；候选覆盖网同时包含标准覆盖设计旋转矩阵 $C(v, k, t)$（严格按 $v \ge k \ge t$ 组合学定义校正参数与容错说明）及 $\le 10$ 张票以内的全部合法子串组合（含不相交分块串如 `7场拆2张3串1`），通过精确线性规划松弛 / 迭代水准填充与整数邻域搜索最大化条件概率加权错 1 场 CVaR 与保底回血，并在卡片与推导依据中披露 `错 >= 2 场击穿率`；
   - **槽位④（`alpha-radar`）**：仅当收缩校准后存在单腿 $O \cdot p_{\text{shrunk}} \ge 1.01$（`>= +1.0% +EV`）且成单（单关或必要时仅配 1 场最高期望返还稳胆且整单总 `expectedValueRate > 0`）保持严格正期望时才激活 `available: true`；彻底移除负期望多场共振串与同义替换主动建仓分支，清除全栈 `"零风险"` 字样；
   - **双端卡片与凯利仓位护栏**：配单卡片第 2 格按真实 `underwaterCount` 动态展示 `0 假中奖倒贴` 或 `⚠️ 含 X 组局部回血(<本金)`，第 3 格主数字展示校准 `数学期望 EV%`（副标展示票面返还率）；`recommendedBankrollPct` 在 `expectedValueRate <= 0` 时按凯利准则封顶为 `1% ~ 2%`（按风险分档 `1%` 或 `2%`），仅在 `expectedValueRate > 0` 时按四分之一凯利（上限 `5%`）给出仓位参考。
5. **真实体彩完场 OOS 数据集与无偏四层基准套件**：
   - 原合成样本重命名为 `syntheticCoherenceFixture.json`；新增冻结的 240+ 场中国体彩官网完场五池实盘数据集 `realSportteryOosMatches.json`（含红队 112 场原始集完整超集，每场带真实 `matchId`、停售最终五池固定奖与官方结算赛果，经自动化脚本校验 `0` 星期错位与 `0` 比分赔率档位违规）；
   - 四层科学基准升级：
     - **Layer 1（240+ 场真实体彩 OOS 校准度 + 万次配对 Bootstrap）**：全五池考核 `Log-Loss`、`Brier Score` 与等质量分位 `ECE`，仅对序数池（`HAD / HHAD / TTG`）考核 `RPS`，输出 10,000 次配对 Bootstrap 95% 置信区间与双侧 $p$ 值，断言闭合模型在真实 OOS 上相对等比去水五池与单池 `Shin` 的 `Log-Loss` 均显著更优（$p < 0.05$），且 `Brier Score`、序数 `RPS` 与分位 `ECE` 点估计均不劣于基线（零退化）；
     - **Layer 2（公理与极端边界零误差不变量）**：覆盖五池闭合、零近似线性期望（含 $> 16,384$ 状态大复式）、`> 2,048` 注显式阻断、全选项缓存失效、`GB/T 8170` 舍入与 8 场 `8串247` `< 15ms` 延迟门禁；
     - **Layer 3（无筒仓万次蒙特卡洛帕累托前沿与精确 0-1 背包对账）**：移除自克隆与关数筒仓过滤，采用单调无条件风险收益指标检验四维非支配性，并直接验证槽位①与独立 0-1 背包全局整数最优零差距；
     - **Layer 4（同规则双轨止损账本消融回放）**：新旧策略统一执行完全相同的每日 `¥300` 止损护栏（无 `forceConfirmed` 双标），对同日盘面做顺序置换稳健性校验，并按扣除模拟踏空红单利润后的真实净免损额核算模拟盘价值。
