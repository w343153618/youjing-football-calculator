## Problem Statement

在独立 Python（`numpy` / `scipy.optimize.milp` / `Decimal`）对 `v2.3.0` 精算内核与双端交互链路执行对抗式科学盲审后，检出 3 项严重数学/诚实性缺陷（P0）、6 项中度偏差（P1）及 4 项边界体验瑕疵（P2）：

1. **超大商集（`> 131,072` 联合状态）状态归并扭曲真赚钱率（P0）**：当合法复式选单（`<= 2,048` 注，例如 8 场各选 5 个总进球打 `2串1` 共 `700` 注、联合状态 $6^8 = 1,679,616$）跨越精确状态枚举阈值时，单场商集压缩将两个不同水位的命中态强行并入同一代表元集合，抹平了高水选项的独立派奖贡献，导致真实盈利概率被系统性低估达 `5.17` 个百分点。
2. **双场容错缩水同场互斥单关错加与逆转归零死角漏报（P0）**：在 2 场目标池下，容错档为同一场比赛配置两张严格互斥的半全场单关缓冲垫（如 `胜胜` 与 `平胜`），却将两者奖金直接相加承诺为「黑掉 1 场保底拿回 ¥X」；实际结算时两张单关绝不可能同时命中，且一旦踢出半场逆转（如 `负胜`）实际派奖为 `0` 元，同时击穿率在部分双场盘面较真实全黑率低报逾 `30` 个百分点。
3. **早晚场对冲无视体彩单关资格且将净亏损标绿称保本（P0）**：中国体彩超 `86%` 实盘赛事的胜平负与让球胜平负未开单关，对冲计算器（含内置早晚锁利演示预设）未校验末场反向池单关资格即推荐单独补单，导致前场红单后线下体彩店根本无法打出该反向票；此外约 `27%` 配对因两元偶数取整与双盘抽水导致锁死净亏损，界面仍标绿展示为「提前锁利 / 保本锁回」。
4. **65 ~ 2,048 注三模奖金优化假成功提示但静默回退等倍（P1）**：内部方案对象合法性校验将防客户端篡改的 `64` 条上限同时施加于服务端自生成的三模奖金优化方案，使 `81` 注、`8串247` 等实战复式点击优化后弹出成功提示但底层静默回退为未优化等倍。
5. **赛事腰斩预演未按有效过关数降档单注封顶（P1）**：4 关串关中首场腰斩按 `1.0` 计奖退算为 3 关有效实赛时，按中国体彩规则最高单注封顶须降档适用 `2/3` 关 `20 万元` 限额，现状仍按原 4 关套用 `50 万元` 限额。
6. **5~8 场独立分块冒称旋转矩阵缩水与分配器未计条件错 1 权重（P1）**：不满足任意两场全覆盖（$t \ge 2$）的独立分块串关（如 `双3串1`、`3串1+4串1`）被冠以「旋转矩阵缩水 / 组合覆盖设计」名称；多场击穿率直接采用主干错 $\ge 2$ 场概率而非整单真实归零率；容错分倍器内部使用等权尾部均值而非条件错 1 场概率加权求解。
7. **稳健保本含单关双场重叠候选缺失、纯退本金混同净赚及矛+盾配比次优（P1）**：双场含单关盘面下未纳入合法「单关 + 2串1」重叠零假中奖组合；`netProfit === 0`（仅退回本金）的子票计入真赚钱率未做说明；期望效用单矛+单盾硬锁最小回本倍数而非同成本精确整数对数财富效用最优。
8. **个人账本模拟观察单单向累计免损（P1）**：账本统计仅累加未中模拟单本金，未并列展示已命中模拟单的踏空笔数。
9. **单池开售概率源微偏、拖油瓶体检错位对比、同义双选替换未配平与沙盒滑块非对称（P2）**：单池独立开售时展示概率与内部比分网格存在微差且跨盘和解门控存在阶跃；拖油瓶体检拿砍单后的表面命中率对比砍单前的真赚钱率且可把双场非单关砍成不可出票单场；同义错价切换至双选配平时重置为等倍；主观胜率信心微调滑块区间 `[-15%, +20%]` 向上偏置。

## Solution

在保持五池闭合校准公理、四层真实体彩 OOS 科学基准与商业保密防线 100% 稳固的前提下，实施精算精确化与全栈零诱导诚实风控升级：

1. **超大商集保派奖分布精确积分**：消除跨越枚举阈值时合并不同水位命中态的有损压缩，对自由过关与多串过关复式采用精确美分派奖卷积或无损同派奖等价态聚合，确保 `<= 2,048` 注任意合法复式的真赚钱率、命中率、保底与最高奖金与全张量精确枚举零偏差。
2. **体彩法定有效关数降档封顶与 512 注服务端三模分倍闭环**：赛事腰斩预演时按剔除无效腿后的剩余有效关数核算单注封顶限额；将客户端不可信快照条数上限（`64` 条）与服务端自生成三模奖金优化条数上限（`512` 条）读写分离，对 `513 ~ 2,048` 注超碎复式在界面诚实置灰并说明原因。
3. **容错缩水诚实分类、双场真实分支保底与条件概率加权整数精调**：严格仅对满足两两全覆盖（$t \ge 2$）的设计冠名「旋转矩阵缩水」，将其余分块方案正名为「独立分块容错串」；双场模式优先采用无死角主盘单关垫，同场多张互斥单关按单分支真实最低派奖核算并如实披露半全场逆转归零死角及整单真实归零率 `1 - winProb`；子问题分配器按条件错 1 场概率权重执行水准填充与多元邻域整数精调。
4. **时间差对冲法定单关硬门禁与锁利/减损双轨呈现**：强制要求末场反向互补候选所在奖池开放单关出票资格（同步校准内置早晚锁利教学预设末场的单关配置）；严格按锁定净利正负分流为绿色「时间差对冲锁利（稳赚净利）」、中性「零损锁回本金」与橙色预警「早场红单减损补单（锁死少亏）」。
5. **配单边缘精化、纠偏工具对齐与双边模拟账本**：补充含单关双场的「单关 + 2串1」零假中奖重叠组合择优并标注纯保本退本金分支；单矛+单盾按同成本精确整数对数财富效用寻优；统一单池开售概率源与平滑跨盘和解过渡；拖油瓶体检统一按真赚钱率评估且校验砍场后合法出票性；同义双选替换自动触发平均配平且不破坏单关出票；主观胜率滑块收敛至对称 `[-15%, +15%]`；个人账本模拟观察单并列披露累计未中免损金额与未中/命中踏空笔数。

## Implementation Decisions

### 1. 超大商集无损派奖分布积分与体彩法定封顶降档

- **保派奖分布精确商空间计算**：
  - 对同场单一玩法选单，单场各勾选选项与“未命中”构成严格互斥完备划分；当跨场商状态乘积超过直接笛卡尔展开阈值且无法使用单桶位掩码枚举时，严禁将同一场比赛不同水位的两个命中选项合并为单一代表元赔率；
  - 对自由过关及官方多串组合，采用按场次递推的精确分位派奖分布动态规划或同单场完全等赔率无损合并，确保 `<= 2,048` 注任意合法选单的 `anyWinProb`、`realProfitProb`、`underwaterCount`、`minPayout`、`maxPayout` 与票级线性 `expectedValueRate` 精确无偏。
- **腰斩有效关数驱动单注封顶**：
  - 在计算任意单张实票的法定单注封顶上限时，统计该票中非腰斩退算（`!isVoidLeg`）的**有效实赛关数** $k_{\text{eff}}$：当 $k_{\text{eff}} \ge 1$ 时按 `statutorySingleBetCap(k_eff)` 执行封顶（例如 4 串 1 含 1 场腰斩时按 3 关 `20 万元` 封顶；2 串 1 含 1 场腰斩时按单关 `10 万元` 封顶）；当全部选腿均腰斩退算时按本金 `2 元` 原额返还。

### 2. 分倍方案读写分离安全上界（客户端 `64` vs 服务端 `512`）

- **不可信输入与内部生成分离校验**：
  - 对客户端请求载荷中携带的 `archetype` 快照方案，维持 `snapshotPlan.lines <= 64` 的严格不可信输入上界，守住防事件循环阻塞红线；
  - 对服务端内部由 `optimizeBonusPlan` 实时计算生成的 `bonus` 三模分倍方案，合法实票行数上界放宽至 **`512` 条**，并同步允许 `scaleArchetypePlan` 在内部可信调用路径下处理至多 `512` 条分倍行；
  - 在选单工作区控制器与审单界面中，当 `manualReport.tickets.length > 512`（或 `betCount > 512`）时，`applyBonusOptimization` 明确返回不可用原因（`超出 512 注线下逐票分倍上限，请精简包号或改用 3+1 精算配单`），前端置灰三模优化与一键配平按钮并以提示条如实告知，彻底根除假成功提示。

### 3. 精算配单四档诚实度与整数规划精化

- **槽位①（稳健保本）**：
  - 在双场（`M = 2`）且至少 1 场主盘开放单关的纯客观盘面下，补充「单关护盾 + 跨场 `2串1` 主攻」零假中奖合法重叠实票组合求解器参与全局择优（严格校验全部命中原子态派奖 $\ge$ 总本金）；
  - 精确统计严格净盈利概率（`returnPayout > totalCost`）与含刚好保本（`returnPayout >= totalCost`）不亏本概率，若最优方案含 `netProfit === 0` 的纯退本金实票，在方案推导说明中透明注明含保本回笼保护分支。
- **槽位②（期望效用）**：
  - 在单矛配单盾结构中，解除将护盾固定死锁在最小回本整数倍 $\lceil 2N / u_{\text{shield}} \rceil$ 的硬限制：在给定总注数 $N$ 下，遍历满足矛与盾均不低于保本线（$m_1 u_1 \ge 2N, m_2 u_2 \ge 2N$）的全部合法整数配比 $(m_1, N - m_1)$，精确选取期望对数财富效用最高点。
- **槽位③（容错缩水）**：
  - **严格两两覆盖判定与命名隔离**：新增组合覆盖度纯数学判定器——仅当块集合中每一张块长度 $k < v$ 且目标池任意两场比赛 $\{i, j\}$ 均至少同时出现在一张实票中（$t \ge 2$，含 `C(5,3,2)`、`C(6,3,2)`、`C(7,3,2)`、`C(8,4,2)` 及 `C(8,6,3)` 四组 6 串 1 对偶补集）时，方可置 `isCoveringWheel = true` 并冠名 **「旋转矩阵缩水」**；其余不相交分块或局部图兰边集一律置 `isCoveringWheel = false` 并冠名 **「独立分块容错串」**；
  - **条件错 1 场概率加权分配器**：在子串倍数分配中直接按各场条件错失概率权重 $w_x \propto (1 - p_x) / p_x$ 计算加权下行尾部 `CVaR`，并在两两交换（2-opt）基础上补充三元整数邻域精调（`+1, +1, -2` 与 `+2, -1, -1`），消除等权排序与两元局部极值卡滞；
  - **双场模式保底与全场景归零率诚实披露**：双场模式下若另 1 场具备在售 `HAD / HHAD` 单关资格，优先采用无漏网死角的主盘单关构建回血垫；若同场包含多张互斥单关（如两项半全场单关），该场存活时的保底回血严格取同场各互斥单关派奖的**最小值**（严禁将互斥选项相加），且当存在正路逆转未覆盖死角（如半全场未全包该方向 3 项）时，标题副标与推导说明明确标注逆转死角 `¥0`；同时 `ArchetypePlan` 与推导说明同步透出整单真实归零率 `zeroPayoutProb = 1 - winProb`，杜绝将主干错 $\ge 2$ 场率误当成整单血本无归率。

### 4. 早晚场对冲法定单关硬门禁与锁利/减损双轨契约

- **末场反向单关资格强制校验**：
  - 互补反向盘解析器对 `HAD` 与 `HHAD` 反向单选或同池双选配平候选，强制检查对应奖池 `selling !== false && single === true`；若末场目标反向池未开放单关，直接返回 `{ ok: false, reason: "末场胜平负/让球未开单关，体彩店无法单独补买反向盘对冲" }`；
  - 校准内置回退赛事集中供「早晚锁利」教学演示使用的末场单关标记与水位，使教学演示场景 100% 满足真实体彩单关出票规则且锁定正净利润。
- **锁利 vs 减损语义与视觉分流**：
  - 扩展对冲洞察契约字段 `hedgeMode: "lock-profit" | "break-even" | "reduce-loss" | "unavailable"`：
    - `lockedNetProfit > 0`（`lock-profit`）：抽屉摘要与卡片标题可使用「时间差对冲锁利」，结果行绿色展示 `稳赚净利 +¥X`；
    - `lockedNetProfit === 0`（`break-even`）：中性色展示 `零损锁回本金 ¥totalCost`；
    - `lockedNetProfit < 0`（`reduce-loss`）：抽屉摘要与说明文案严禁出现 `"提前锁利"` 或 `"保本"` 字样，统一改为客观的 **「早场红单减损补单」**，结果行使用橙色预警色展示 `锁死少亏 -¥|X|（拿回 ¥Y）`。

### 5. 单池概率源对齐、纠偏工具防护、对称沙盒与双边模拟账本

- **单池校准一致性与平滑和解过渡**：
  - 当赛事仅单池在售时，将单池 `Shin` 去水概率通过最小相对熵单池边际投影回写至 `scoreGrid` 与 `poolProbs`，使展示 `fairProb` 与微观 `xG` / 卡盘率严格同源；将 `HAD` 与 `HHAD(±1)` 跨盘和解门控由 `0.12` 硬阶跃改为 `[0.10, 0.16]` 线性余弦/斜坡平滑衰减权重，消除微小赔率变动引发的概率跳变。
- **串关拖油瓶体检与同义替换防呆**：
  - 拖油瓶敏感度体检改用精确重算砍掉目标场次后的真实选单报告：仅当砍场后剩余选单**仍满足合法出票条件（`canCheckout === true`）**且砍场后的真实 `realProfitProb` 较当前 `report.realProfitProb` 提升 `>= 14` 个百分点时才弹出建议；
  - 同义错价替换：若当前为单场选单且劣势项具备单关资格而优势双选所在奖池未开单关，则不生成破坏出票资格的替换提示；当用户在审单台执行 `betterPicks.length >= 2` 的同义双选配平替换且替换后总注数 `<= 512` 时，控制器自动联动挂载 `equal` 平均优化分倍以兑现「配平」承诺。
- **对称主观胜率沙盒与双边模拟账本**：
  - 主观胜率信心微调滑块范围统一调整为对称区间 **`-15% ~ +15%`**（服务端入参钳制同步对齐）；
  - 账本统计结构 `LedgerStats` 新增 `paperLostCount: number` 与 `paperWonCount: number`（向后保留 `paperCount` 与 `paperSavedAmount`），界面第 4 格统计副标升级为 **`模拟未中免损 (X未中/Y命中)`**，模拟单条目结算为命中时标注 `🎯模拟命中(未实买)`。

## Testing Decisions

- **好测试的黄金准则**：全部测试严格建立在预确认的公开模块接缝处，以独立计算的精确数学真值（Python/解析真值字面量或无压缩精确枚举对照）作为预期断言基准，严禁同义复写生产代码逻辑，严格按「写 1 个失败测试（Red）→ 写最小实现转绿（Green）」垂直切片推进。
- **三大公开测试接缝（Seams）**：
  1. **Seam 1 · 服务端精算内核公开接口接缝**（`calibrateMatchCoherentModel`、`computeTruthReport`、`optimizeBonusPlan`、`generateParetoPortfolio`、`computeProOrderInsights`、`evaluateQuantWorkspace`）：
     - 验证 `> 131,072` 联合状态合法复式（如 8 场 5 项总进球 `2串1` 共 700 注、6 场 7 项总进球 `2串1` 共 735 注）的 `realProfitProb`、`anyWinProb`、`minPayout`、`maxPayout` 与精确分步卷积真值误差 `< 10⁻¹²`；
     - 验证 4 关串关开启首场腰斩退算 `1.0` 时，单注封顶精确降档至 3 关 `200,000` 元（2 关串关首场腰斩降档至单关 `100,000` 元）；
     - 验证 `65 ~ 512` 注（如 `4场全包81注`、`8串247`）执行三模奖金优化后 `appliedPlan` 非空且真实生效，而不可信 `archetype` 快照超 `64` 条仍被安全拒绝；
     - 验证槽位③双场同场互斥单关绝不相加、存在半全场逆转死角时如实标注且透出精确 `zeroPayoutProb`，5~8 场仅 $t \ge 2$ 设计标为「旋转矩阵缩水」且概率加权 `CVaR` 优于等权基线；验证槽位①含单关双场重叠组合择优与槽位②单矛+单盾同成本精确对数效用最优；
     - 验证早晚场对冲在末场未开单关时严格返回 `available: false`，在 `lockedNetProfit < 0` 时返回 `hedgeMode: "reduce-loss"` 且零 `"锁利/保本"` 误导词；验证单池开售概率同源、平滑和解连续性与拖油瓶体检合法出票守卫。
  2. **Seam 2 · 选单工作区控制器与服务端账本运行时接缝**（`createBetSlipController`、`createLedgerManager` / `createYouJingRuntime`）：
     - 验证 `> 512` 注复式调用 `applyBonusOptimization` 返回明确阻断提示而不写入无效 `planSpec`；
     - 验证点击双选同义替换后自动联动平均配平且不破坏单场单关出票资格；验证主观胜率滑块钳制于 `[-15, 15]`；
     - 验证双轨账本结算模拟观察单后精确返回 `paperLostCount`、`paperWonCount` 与 `paperSavedAmount`。
  3. **Seam 3 · 生产零泄露构建与真实浏览器双视口接缝**（`pnpm run check:guardrails`、`pnpm run bench:quant`、`pnpm build` 及 `ego-browser` 桌面 `1520×920` / 移动 `390×844` 核验）：
     - 验证四层真实体彩 OOS 科学基准套件全绿、`dist/` 零 `.map` 且零明文中文字符；
     - 在双视口真实浏览器下核验：早晚锁利演示与减损预警橙色样式、超 512 注置灰提示与 `<= 512` 注真实优化、容错缩水真实分类与双场保底披露、对称 `[-15%, +15%]` 滑块及账本双边模拟统计展示。
