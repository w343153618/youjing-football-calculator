# Spec 0001: 优竞体育内部专用 · 超感物理动效、多维震动体感与全链路精算审计规范

Status: `ready-for-agent`

## Problem Statement

普通体育彩票计算器（包括体彩官网计算器）不仅隐藏了真实暗扣抽水率、去水真实胜率与「假中奖（水下倒贴）」组合，而且交互干瘪生硬——点击赔率、切换奖金优化或核对实票时缺乏真实的物理重量感、视觉因果反馈与手机震动体感，难以让内部专业用户在高频看盘与店面出票场景中获得清晰、防错且极具高级感的操控体验。同时，跨多场串关分倍优化、边界赔率舍入与容灾路由需要经过严格的契约测试与多维代码审查，确保零算术偏差与零资源泄漏。

## Solution

在「优竞体育内部专用」双端自适应工作台（手机端 `100dvh` 贴边布局 + 电脑端宽屏三栏工作台）基础上，构建统一的深模块「超感物理与多维触觉交响引擎（Tactile Symphony Module）」，将 240Hz 弹簧动力学、抛物线磁吸弹道、指尖冲击波、实时奖金天平柱状图、全息陀螺仪流光票面与三通道手机触感反馈（Android 多段波形震动 + iOS Safari Taptic 硬件微动 + 可选 WebAudio 拟真机械微声场）深度融合至 8 套材质皮肤；并通过契约边界单元测试与多 Agent 双轴交叉代码审查（Standards + Spec + Bug Hunt）锁死全链路质量。

## User Stories

1. 作为内部看盘人员，我希望点击任意赔率按钮时看到带尾迹的赔率能量球沿抛物线飞入底部注单条（或桌面审单舱）并触发落袋下沉回弹与双段磁吸震动，以便在快速点选时获得明确直觉的入筐确认感。
2. 作为手机端用户，我希望每次按压按钮时在指尖触点绽放贴合当前皮肤色彩的水波冲击环，并伴随保持体积感的果冻挤压回弹形变，以便感受媲美原生硬件键盘的按压质感。
3. 作为切换不同视觉皮肤的用户，我希望 8 套皮肤（素白、瑞士、工坊、点阵、水墨、琉璃、表盘、草坪）不仅视觉材质不同，还各自拥有专属的弹簧刚度阻尼与震动波形特征（如瑞士棘轮清脆卡点、表盘陀飞轮多连脉冲、草坪重炮弹性回馈），以便每套皮肤都具备独特的物理生命力。
4. 作为同时使用 iPhone Safari 与 Android 浏览器的团队成员，我希望震动引擎在 Android 上输出多段毫秒级节奏波形，在 iOS 17.4+ Safari 上自动桥接原生 Switch Taptic 硬件微动，并提供可选的零延迟 WebAudio 拟真机械微动声效，以便在不同手机系统上都能获得清晰体感。
5. 作为使用智能奖金优化（平均优化 / 博热保本 / 博冷高弹）的用户，我希望点击优化模式时看到流光扫频与实时弹簧生长的「各组合派奖 vs 本金红线」动态天平柱状图，并伴随上行琶音式多段震动，以便一眼看清原本水下亏钱的红色短柱如何被拉升至本金线之上。
6. 作为手选复式注单的用户，我希望当注单出现「假中奖倒贴」时收到红色心电微震与双段警示震动，而在点击「一键配平 100% 全保本」解除风险或完成店面全部实票打钩核对时绽放 360° 物理重力微粒礼花与解锁震感，以便强化防坑警觉与锁利正反馈。
7. 作为调节「主观胜率信心微调滑块」的用户，我希望滑动经过每一个整数百分比刻度时触发犹如机械表冠棘轮般的微刻度震感（且归零位 `0%` 有明显磁吸卡顿），以便单手盲操也能精准控位。
8. 作为呼叫「扫地僧小高实时排雷」的用户，我希望在等待推演期间看到声呐雷达扫描波纹，结果返回瞬间以密文解码式弹簧揭示并触发锁定脉冲，且界面全程严格显示「扫地僧小高」绝不暴露底层模型字样。
9. 作为在线下体彩店出示防错打票单的用户，我希望倾斜手机（陀螺仪）或滑动指尖时票面呈现 3D 全息银联级流光折射，点击逐行核对时产生检票盖章回弹震感，且多场串关优化后的每张分倍实票完整保留全部串关场次明细绝不丢失腿数。
10. 作为对震动敏感度不同的用户，我希望顶部提供「🎮 超感舱」面板，随时切换体感强度（静音 / 柔和 / 标准 / 狂暴超感）、开关拟真机械微声效，并能一键触发全套超感连招演示。
11. 作为手机浏览器与电脑浏览器双端用户，我希望手机端保持无假边框的 `100dvh` 全屏单手触控排版，电脑端呈现左中右三栏同屏联动工作台，且两端随时可打开图文并茂的内置精算说明书查阅任意专业名词。

## Implementation Decisions

- **深模块封装（Tactile Symphony Module）**：将多通道震动驱动（Android `navigator.vibrate` 波形缩放 + iOS Switch Taptic 隐藏触发器 + WebAudio 合成器）、8 皮肤触觉预设映射、抛物线粒子弹道、指尖冲击波与微粒礼花统一封装在单一深模块接口之后，UI 层仅需声明语义化动作（如选号飞入、优化配平、雷区警报、盖章核对、刻度棘轮），无需感知底层 DOM 粒子生命周期或平台兼容细节。
- **组合明细完整溯源**：`computeTruthReport` 生成的每一个 `ComboBreakdown` 必须完整携带构成该单注的所有串关选号腿（`legs`），确保「平均优化 / 博热保本 / 博冷高弹」在 2串1 至 8串1 多场串关场景下生成的分倍实票与店面防错打票单 100% 精确展示每一场对阵与选项。
- **粒子与动画零泄漏铁律**：所有抛物线飞弹、指尖水波与礼花微粒统一挂载在固定 `pointer-events: none` 特效层，生命周期结束后立即回收 DOM 节点；组件卸载或弹窗关闭时严格清理监听器与定时器。
- **精算与情报严格解耦（遵循 ADR-0002）**：数学引擎独立运行中国体彩「四舍六入五成双」与法定限赔截断；「扫地僧小高」网关严格遵循 `deepseek-v4.1-flash` 优先、故障自动切 `glm-5.3-flash`、恢复自动切回策略。

## Testing Decisions

- **好测试的准则**：仅在模块的公开契约接缝（Seam）处验证业务可观测行为与已知精算真值，严禁耦合私有实现或编写同义反复（Tautological）断言。
- **核心测试接缝（Seams）**：
  1. **体彩计奖与五维真相接缝（`bankerRoundCents` & `computeTruthReport`）**：验证 `.005` 奇进偶舍边界、20万/50万/100万法定封顶截断、同场跨玩法冲突提示、假中奖组合识别以及多场串关 `legs` 完整性。
  2. **五流派与三模奖金优化接缝（`generateFiveArchetypes` & `optimizeComboMultiples`）**：验证 5 大流派生成、刺客流 36% 轻仓护栏、平均优化/博热保本/博冷高弹在单场及多场串关下的保本配平与总成本精确性，以及时间差锁利对冲公式。
  3. **扫地僧小高主备容灾路由接缝（`invokeWithAutoFailover`）**：通过可注入请求适配器验证正常态优先走主模型 `deepseek-v4.1-flash`、主模型抛错时零报错无缝降级至 `glm-5.3-flash`、冷却期防抖及主模型恢复后自动切回。

## Out of Scope

- 真钱在线代购或自动下注接口（严格定位为内部精算分析、风控排雷与线下体彩店防错核对工具）。
- 依赖外部大型音频/视频资源文件的重型特效（全部音效与粒子均采用毫秒级纯代码实时合成，确保首屏秒开）。
