# Spec 0012 · 二期红队盲审精算矫偏、预算主权守恒、胆拖过桥实战三大件与素颜双轨工作台

Status: ready-for-agent
Date: 2026-11-21
Related ADRs: ADR-0001, ADR-0002, ADR-0007, ADR-0008, ADR-0010, ADR-0011, ADR-0012, ADR-0013

## Problem Statement

在结合 826 场中国体彩完场真盘（含 204 场仓库区间外零污染盲测集）、42 场在售实时盘口与 1,080 组组合压力注单执行第二轮独立科学盲审后，站在专业竞彩优化计算器与普通购彩用户视角暴露出六大痛点：

1. **三模奖金优化擅自暴涨用户本金、千元级分倍被 `99倍` 误截断且存在假稳赚标签**：用户在 27 注复式上原投 `¥54`，点击「博热保本」后本金未经同意静默飙升至 `¥278`（`5.15倍`）且仍有 25 注水下倒亏；千元级注单（如 `¥1,000`）因内部修复器硬截断逻辑倍数为 `99`，导致反比例配平退化为 `1:1` 等倍并产生中奖倒亏；在非互斥 `M串N` 或本金不足以全保本时，仍硬编码输出“全选项均衡稳赚 / 彻底消灭假中奖倒贴”误导文案。
2. **五池校准单向泊松截断制造实盘伪 `+EV` 假阳性且遗漏深让球盘**：单向截断器无视子盘官方更新时间戳新旧，强行将低于泊松先验的子盘概率向泊松网格拉高 `85%`，在实盘（如比分池已最新反映 `2:1` 而非 `1:0` 的场次）误触发 `错价雷达` 买入信号；同时 `±2 / ±3` 深让球盘跳过了主让球跨分割对齐，主盘全盘套用欧洲庄家 `Shin` 公式高估了国内竞彩 `<1.55` 低赔大热的期望返还。
3. **`3+1 精算配单` 静默偷换关数、平手混充净赚且大额预算账面蒸发**：无锚定自由选池下用户圈定 `3 ~ 8` 场比赛时，`① 稳健保本` `100%` 静默丢弃其余 `M - 1` 场仅买 1 场单关以拉高账面胜率，与满场方案形成错位对比；将净赚 `¥0.00`（纯退本金）计入“真赚钱率”造成近 15 个百分点虚高；输入 `¥5,000` 合法预算时，槽位①/②受内部注数硬锁限制仅花掉 `¥1,000 ~ ¥1,998` 且 `savedCash` 为 `0`，数千元预算在卡片上凭空消失。
4. **主观倾向与信心滑块如同“十级美颜”覆盖客观真账**：用户切换「偏主队 / 防爆冷」或拉动 `±15%` 主观信心滑块后，系统用主观扭曲概率直接覆盖主看板的期望回报率与真赚钱率，将 `-20.6%` 的客观负期望串关显示成 `+5.0%` 正收益，极易诱导盲目加仓。
5. **缺少国内竞彩最核心的「设胆（胆拖过关）」与「单场凑 2 串 1 过桥配菜寻优」**：用户选 3~8 场比赛含稳胆与防平双选时，无法像体彩实体店终端那样通过“设胆”一键砍掉无胆冗余组合并单票打出；当仅看准 1 场未开单关赛事（占竞彩 85%+）时，系统无法自动从全盘筛选抽水最低或晚场可单关对冲的最佳“黄金搭子”凑 `2串1`。
6. **忽视实体店两元凑整反杀、超长伤停补时踏空与零碎票打票滑点**：同义双选比价未代入用户真实预算核算 `¥2` 整数倍离散保底，导致 `¥10 ~ ¥30` 小本金听信推荐拆双选反而比单买拿钱更少；早晚场对冲 `110 分钟` 阈值不足以覆盖现代足球超长补时加提前停售窗口；多张相近倍数零碎票缺乏合票减张开关，拿去实体店易遭拒打或遭遇中途变赔滑点。

## Solution

在不推翻现有「① 赛事雷达选球 → ② 3+1精算配单 → ③ 审单锁利打票」双端三步骨架的前提下，实施后端精算内核深度矫偏与 5 处嵌入式微创 UI 协同升级：

1. **三模奖金优化预算主权守恒 + 保本门槛一键升级条**：严格锁死用户当前预算上限做最优整数分配或最优减损，放开逻辑倍数上限至 `999`（按 `99` 倍核算实体店拆票张数），支持 `M串N` 联合状态保底优化；当原预算不足以清零假中奖时诚实展示剩余局部回血组数，并提供「⚡ 一键加至最低保本门槛 ¥X」显式授权按钮。
2. **实证时间戳滞后校准 + 全整数让球线闭合**：废除无视时间戳的单向泊松拉高截断，仅在子盘官方更新时间真实早于主盘 `>= 30 分钟` 且跨盘等价事件同向支撑时认定调水滞后；将主让球跨分割对齐推广至 `±1, ±2, ±3` 全整数让球线，主盘采用契合国内竞彩返还特征的温和去水核，并将混串抽水预警覆盖至综合返还率 `< 72%` 的高抽水子盘混串。
3. **`3+1` 满场公平对比 + 大额预算闭环 + 净赚/保本双口径拆解**：无锚定与锚定模式下 `① 稳健保本` 均强制保留用户所选全部合法场次公平求解（若精简至 1~2 场更优，仅在卡片底部文字提示，绝不静默删比赛）；大额预算支持等比扩仓至目标预算并严守 `实投 + 省下现金 === 预算` 账目闭合；全面拆分展示 **严格净赚率（`netProfit > 0`）** 与 **平手保本率（`netProfit === 0`）**。
4. **素颜客观真账锁死 + 个人信心双轨并列**：无论开启何种看球倾向或拉动主观信心滑块，主看板与配单卡核心大字永远锁定显示 **客观期望回报率** 与 **客观严格净赚率**；个人倾向/滑块推演结果单独以对照小字/胶囊并列展示。
5. **原生「📌 设胆（胆拖过关）」+「🌉 过桥配菜场寻优」+「🧾 实体店防坑套件」**：
   - 在已选场次弹窗、过关选择面板与审单已选对阵明细中嵌入 **「📌 设胆」** 开关（`M >= 3` 且自由过关最小关数 `>= 2` 时支持设定 `1 ~ (k_min - 1)` 场必出稳胆，打票核对单同步标出 `【胆】`）；
   - 单选 1 场非单关赛事被阻断时，在底栏与审单提示卡精选推荐最多 **Top 2 黄金过桥搭子**（① 全盘最低抽水稳胆搭子、② 开球间隔 `>= 135 分钟` 且反向互补池开单关的时间差锁利搭子），支持「一键搭上」凑成合法 `2串1`；
   - 同义双选比价代入当前真实预算校验 `¥2` 整数注离散保底严格占优才触发推荐；早晚场安全对冲间隔上调至 **`135 分钟`**；防错打票单新增 **「🔗 智能合票减张」** 开关（默认开启相近倍数聚类合并，支持一键切回精确分倍）。

## User Stories

1. 作为购彩成员，我希望点击「平均优化 / 博热保本 / 博冷高弹」时系统严格不超过我当前设定的投注总本金，这样我就不会被系统暗中把 54 元注单放大到 278 元。
2. 作为购彩成员，当我当前的本金在数学上确实不够让每注都保本时，我希望看到诚实的局部回血提示以及准确的「最低保本门槛金额 ¥X」一键升级按钮，由我自己决定是否加钱保本。
3. 作为大额购彩成员，当我投入 `¥1,000 ~ ¥20,000` 进行单关或串关奖金优化时，我希望系统按真实反比例或主攻护盾比例精确分配逻辑倍数（最高至 `999` 倍）并自动换算体彩店 `99` 倍分票张数，而不会把所有选项强行截断成 `99:99` 等倍导致中奖倒亏。
4. 作为喜欢买 `3串3`、`3串4`、`4串11` 等多串过关的成员，我希望奖金优化按实际联合命中场景（错 1 场存活子票派奖）优化保底回血，并在无法全保本时如实告知回血比例，绝不虚假标榜“全选项均衡稳赚”。
5. 作为使用 `3+1 精算配单` 圈定了 3~8 场心仪比赛的成员，我希望「① 稳健保本」老老实实保留我选的全部场次在同一起跑线对比，若精简至 1~2 场胜率更高仅在卡片底部文字提示我，而不会背着我偷偷删掉其余比赛。
6. 作为大额配单成员，当我在 `3+1 精算配单` 输入 `¥2,000 ~ ¥20,000` 预算时，我希望四档方案充分利用合法预算或如实显示剩余省下金额（满足 `实投 + 省下 === 预算`），不会出现几千元预算账面蒸发的黑洞。
7. 作为关注真实盈利的成员，我希望界面将「严格净赚率（多赚至少 1 分钱）」与「平手保本率（净赚 ¥0.00 纯退本金）」拆开展示，这样我就不会被平手退本金充数的赚钱率误导。
8. 作为使用「偏主队 / 防爆冷」倾向或「主观胜率信心滑块」的成员，我希望看板核心大字永远锁定显示客观盘面期望与客观净赚率，我个人的主观推演值单独列在旁边对照，防止“美颜滤镜”哄自己盲目重注。
9. 作为信任 `错价雷达` 的成员，我希望系统仅在子盘官方更新时间真实滞后主盘且跨盘等价赛果同向支撑纯正期望时才触发买入推荐，杜绝因刚性泊松先验强压最新比分盘而误报伪 `+EV` 信号。
10. 作为投注强弱悬殊深盘（让球 `±2 / ±3`）或高抽水子盘混串（如胜平负串比分）的成员，我希望五池校准在任意整数让球线下保持跨分割自洽，且当混串综合返还率低于 `72%` 时及时收到高抽水预警。
11. 作为选了 3 场及以上比赛准备打低关自由过关（如 4 场打 `3串1` 或 `2串1+3串1`）的成员，我希望能在「已选场次弹窗 / 过关选择面板 / 审单已选列表」中将最有把握的 1~2 场比赛点亮为「📌 胆」，一键剔除不含稳胆的废票、立省本金，并在防错打票单上清晰看到 `【胆】` 标记。
12. 作为当期只看准了 1 场未开单关比赛的成员，我希望底栏与审单区能直接给我精选最多 2 个最佳「🌉 过桥配菜搭子」（全盘最低抽水稳胆搭子 + 间隔 `≥135分钟` 晚场可单关反向锁利搭子），点一下就能搭桥凑成合法 `2串1`。
13. 作为预算 `¥10 ~ ¥30` 的小额成员，我希望同义买法比价先按我当前的真实本金核算 `¥2` 整数倍出票后的实际保底派奖，只有拆买双选真实到手保底严格高于单选时才推荐替换，防止因两元凑整反而少拿钱。
14. 作为使用早晚场时间差对冲的成员，我希望系统按 `≥ 135 分钟` 的实战安全间隔（预留现代足球超长伤停补时与体彩店提前停售时间）判定可对冲窗口，并对 `110 ~ 134 分钟` 的临界间隔给出补时踏空风险提示。
15. 作为拿着方案去线下体彩实体店打票的成员，我希望在「🧾 防错打票单」中默认开启「🔗 智能合票减张」，把相近倍数的零碎单合并成少量实票快速扫出防中途降赔滑点，同时保留切换回精确逐票分倍的自由。
16. 作为联合调用「扫地僧小高」多场会诊的成员，我希望小高能准确感知我当前是否启用了胆拖定胆、过桥搭子或预算内减损分倍，给出前后自洽的协同排雷建议。
17. 作为在电脑三栏工作台、手机浏览器与安卓原生伴侣端切换使用的成员，我希望这 5 处嵌入式微创 UI 在 `≥960px` 宽屏与 `390px` 手机最挤状态（含超管 `👑总控` 按钮）下均排版紧凑、零横向溢出，且最新安卓 APK 同步可用。

## Implementation Decisions

1. **校准与错价扫描深模块修正**：
   - 将主让球跨分割去水对齐推广至任意非零整数 `goalLine`（根据比分网格净胜球 `d + goalLine` 严格划分正路、卡盘、受让三集合对齐主盘与让球盘边缘）；主盘（`HAD` / `HHAD`）采用温和幂次与等比混合去水以贴合国内竞彩低赔严控实况，细分子盘（`HAFU` / `TTG` / `CRS`）保留幂次/非线性长尾去水。
   - 废除无条件单向拉高子盘的 `huberLagCap`；新增官方 `updateTime` 时间差解析器：仅当子盘更新时间真实早于主盘至少 `30 分钟`，且跨盘同义/包含集合不与该正偏离冲突时，才允许向跨盘先验温和回拉；否则严格尊重子盘与比分盘最新实盘定价。
   - 将串关暗扣抽水雪崩预警条件扩展为 `avgPassLen >= 4 || avgPayoutRatio < 0.72`，覆盖 2~3 关高抽水子盘混串。

2. **三模奖金优化契约升级（预算守恒 + 显式升级 + `M串N` 联合保底 + 合票压缩）**：
   - 扩展 `AppliedPlanSpec` 中 `bonus` 分支支持可选 `upgradeToBreakeven?: boolean` 与 `consolidateTickets?: boolean`。
   - 默认（`!upgradeToBreakeven`）严格以 `manualReport.totalCost` 为硬性预算上限分配整数倍数；逻辑单行倍数上限统一提升至 `999`（移除 `Math.min(99, m)` 误截断，实体店打印层按 `ceil(mult / 99)` 计算张数）。
   - 计算精确 `breakevenUpgradeCost`（覆盖 `<= 512` 注，求解满足 $\sum_i \lceil B / u_i \rceil \le B / 2$ 的最小偶数预算 $B \le 20,000$）；当用户点击「一键加至最低保本门槛」设置 `upgradeToBreakeven: true` 时，以 `breakevenUpgradeCost` 为目标预算实现 100% 零倒贴配平。
   - 当输入注单为非互斥 `M串N` 或多关叠加时，利用联合命中状态矩阵优化最差存活场景派奖；当优化后 `underwaterCount > 0` 时，方案 `title` / `badge` / `reasons` 自动切换为诚实的“预算内最优减损配比（仍含 X 组局部回血）”表述。
   - 提供相近倍数**合票压缩**视图（`consolidatedLines`）：在保持总本金不变且保底回血偏离受控（`<= 3%`）的前提下，将相同过关阶数且倍数相近的实票聚类合并为复合复式/同倍票组供「🧾 防错打票单」直接展示，用户可一键切换精确视图与合票减张视图。

3. **`3+1 精算配单` 满场公平、大额扩仓与客观/主观双轨数据契约**：
   - 无锚定自由选池下，当 `selected.length >= 2` 时，槽位①（`max-profit-prob`）仅在包含全部所选合法场次（受玩法最高过关上限约束）的候选空间内求解精确 0-1 背包最优解；同时快速测算核心 1~2 场保本上限并写入 `reasons` 底部轻量提示，绝不静默删减场次。
   - 当 `cleanBudget` 超出单次背包基础注数窗口（如 `¥2,000 ~ ¥20,000`）时，在单行逻辑倍数上限（`<= 999` 或多行扩仓）与法定封顶红线内执行精确等比扩倍与余注水准填充，并严格赋值 `savedCash = Math.max(0, cleanBudget - totalCost)`，确保每一分预算去向透明闭合。
   - 在 `TruthReport` 与 `ArchetypePlan` 中同步新增双口径与客观锚定字段：
     ```ts
     interface ObjectiveAndSplitMetrics {
       strictNetGainProb: number; // netProfit > 0 严格净赚概率
       breakEvenProb: number; // netProfit === 0 平手退本概率
       objectiveEVRate: number; // 锁死客观校准概率下的期望回报率
       objectiveProfitProb: number; // 锁死客观校准概率下的不亏率
       objectiveStrictNetGainProb: number; // 锁死客观校准概率下的严格净赚率
       subjectiveProjectedEVRate?: number | null; // 开启非客观倾向或滑块!=0时的个人推演EV
       subjectiveProjectedProfitProb?: number | null; // 开启非客观倾向或滑块!=0时的个人推演不亏率
     }
     ```

4. **原生胆拖定胆（`bankerMatchIds`）与全盘过桥配菜寻优（`bridgeCandidates`）**：
   - 扩展 `PassSelectionSpec` 增加 `bankerMatchIds?: string[]`：
     - 合法约束：仅在 `matchCount >= 3` 且自由过关模式（非 `M串N` 固定多串）下生效；有效胆码集合 $B$ 仅保留当前仍在选单中的 `matchId`，且自动裁剪至 $|B| \le \min(\text{activePassSizes}) - 1$。
     - 精确组合预估与展开：对于每个过关阶数 $k \in \text{activePassSizes}$（$k > |B|$），必选全部 $|B|$ 场胆码，再从剩余 $M - |B|$ 场拖码中取 $k - |B|$ 场子集做初等对称多项式精确计数（超 `2,048` 注同样零截断显式阻断）并展开实票；`modeLabel` 自动标注如 `3串1(1胆)`，打票单明确标识 `📌【胆】`。
   - 在 `ProOrderInsights` 中新增 `bridgeCandidates: BridgeMatchCandidate[]`：
     - 触发条件：`matchCount === 1 && !canCheckout`（单选 1 场非单关赛事被阻断）。
     - 从 `matches` 其余在售赛事中扫描主盘（`HAD` / `HHAD`）合法过关选项，精选最多 2 项互异候选：
       1. `lowest-vig`（🛡️ 全盘最低抽水稳胆搭子）：综合单腿客观期望返还 $O \cdot p_{\text{obj}}$ 最高且正路概率稳健（$\ge 48\%$）的首选搭子；
       2. `staggered-hedge`（⏰ 晚场时间差锁利搭子）：与当前已选比赛开球间隔 $\ge 135\text{ 分钟}$、且其反向互补池开放单关出票资格的最佳晚场（或早场）搭子。

5. **实体店防坑套件（预算感知同义比价 + `135 分钟` 对冲安全线）**：
   - `computeProOrderInsights` 中的 `activeSwapTip`（双选配平替单选）代入用户当前注单在目标场次的实际可用注数 $N \ge 2$，校验最优整数拆注 $(m_1, N - m_1)$ 的最坏派奖严格大于单选 $N$ 注派奖时才激活提示；单场比价徽章补充小额离散凑整门槛说明。
   - 早晚场时间差对冲安全间隔从 `110 分钟` 提升至 **`135 分钟`**；当间隔处于 `[110, 135)` 分钟临界区时，在不可用原因中明确提示“存在伤停补时与提前停售踏空风险（建议间隔 ≥135 分钟）”。

6. **五处嵌入式微创 UI 协同与双视口预算**：
   - **已选弹窗 / 过关面板 / 审单已选列表**：当 `matchCount >= 3` 且处于自由过关低关模式时，每场右侧渲染紧凑 `📌设胆` / `📌胆` 切换胶囊；
   - **选球底栏 & 审单提示卡**：单场非单关阻断态下展示 Top 2 `🌉 过桥配菜搭子` 快捷卡片及「一键搭上」按钮；
   - **审单透视舱 & 配单大卡**：核心大字固定渲染 `objectiveStrictNetGainProb`（副标并列 `另含 X% 刚回本`）与 `objectiveEVRate`（非客观态副标并列 `个人推演 EV`）；三模分倍在预算不足全保本时展示「⚡ 一键加至最低保本门槛 ¥X」按钮；
   - **防错打票单弹窗**：标注 `📌【胆】` 场次，顶部提供「🔗 智能合票减张」开关；同步更新图文说明书对应词条与问答知识库。

## Testing Decisions

- **好测试的唯一判据**：只围绕公开深模块接缝验证外部可观测输入输出与业务不变量（如预算恒不越界、账目相加恒闭合、胆码必现于每张展开实票、伪 `+EV` 零误报），绝不耦合内部私有辅助函数或数组缓存结构。
- **聚焦三大既有最高层测试接缝（Seams）**：
  1. **Seam 1 · 服务端精算黑盒接缝**（`evaluateQuantWorkspace` 及导出的 `calibrateMatchCoherentModel`、`computeTruthReport`、`optimizeBonusPlan`、`generateParetoPortfolio`、`computeProOrderInsights`）：覆盖预算主权守恒、`999` 倍无误截断、`M串N` 联合状态保底、时间戳滞后防伪 `+EV`、`±2/±3` 深让球闭合、满场公平对比、`¥5,000` 大额闭合、净赚/保本拆分、客观/主观双轨锁死、胆拖精确计数与展开、Top 2 过桥配菜寻优、预算感知离散比价、`135 分钟` 对冲安全线及合票压缩。
  2. **Seam 2 · 无头选单工作区控制器接缝**（`createBetSlipController`）：覆盖 `toggleBankerMatch`（含越界自动裁剪与删场清理）、`applyBridgeCandidate` 一键搭桥成 `2串1`、`upgradeBonusToBreakeven` 显式授权升级、`toggleTicketConsolidation` 合票状态切换及客观基准缓存同步。
  3. **Seam 3 · 小高协同上下文与双视口端到端渲染接缝**（`buildComboDiagnosisContext` + `ego-browser` 桌面 `1440×900` 与移动 `390×844` 实机核验）：验证小高感知胆拖与预算减损结构，核验双端 5 处嵌入式 UI 零横向溢出、零控制台异常。
- **测试先例参考**：延续 `tests/blindAuditRemediation0011.test.ts`、`tests/sportteryRulesPassAndSync.test.ts` 与 `tests/linkageUiAndSynergy0010.test.ts` 的契约式断言与独立暴力枚举对账风格。
