# Spec 0003 · 会员授权与隐形超管总控台、百科级图文铁笼问答、1~8场五流派、双模排雷与 48h 整机熔断（v2.0.0）

> 源自 `grill-with-docs` 全量对齐归档。本规范同步受 `GLOSSARY.md` 与 `docs/adr/0003`～`0005` 约束。

## 1. 全员登录制与 2(b) 隐形超管总控台（`server/accountManager.mjs` + `src/auth/LoginGate.tsx` + `src/admin/AdminConsoleModal.tsx`）

1. **全员登录前置门禁**：
   - 真实浏览器访问时，未持有有效 `authToken` 的会话在 `/api/security/bootstrap` 仅获颁加密握手信封与 `{ authenticated: false }` 状态，**绝不下发任何赛事水位、五流派或精算数据**。
   - AI 读链器与爬虫（豆包、Jina、GPTBot、`curl` 等）依然在第一层直接命中静态时区换算迷魂阵 HTML，连登录框都无法看到。
2. **方案 2(b) 内嵌式 RBAC 隐形总控台**：
   - 普通成员（`role === 'member'`）登录后，顶部栏、抽屉与全部 DOM 中**零管理员按钮、零后台字样**。
   - 唯独超级管理员（`role === 'superadmin'`）登录后，桌面端顶栏与手机端顶栏自动显现 **「👑 总控台」** 按钮；所有 `/api/admin/*` 加密路由在服务端强制校验 `user.role === 'superadmin'`。
   - 支持能力：一键新建账号并复制微信发卡口令、设置首次登录激活时长（`2h / 24h / 3d / 7d / 30d / 自定义小时 / 永久`）、设备绑定上限（默认 `2` 台：1 手机 + 1 电脑，支持后期调整上限与一键解绑换机）、独立开关「扫地僧小高诊盘 / 智能问答」权限与每日调用上限（支持后期提额，北京时间 `00:00` 自动重置）、一键停用/启用、一键续期（`+24h / +7d / 转永久`）、一键解除密码冷却/违规封禁、重置密码、清理测试或废弃账号、修改超管自身密码、查看安全审计与违规提问原文日志。
3. **首次激活计时（First-Login Activation Timer）**：
   - 管理员建号并设定 `durationHours` 时，`firstLoginAt` 与 `expiresAt` 保持 `null`（建号未登录不扣时长）；直到该成员**第一次成功输入账号密码登录**瞬间，才写入 `firstLoginAt = now` 与 `expiresAt = now + durationHours * 3600_000`。
4. **Apple ID / 路由器级阶梯防爆破冷却（Progressive Brute-Force Cooldown）**：
   - 连续输错密码第 `1~4` 次提示剩余容错次数；第 `5` 次锁 `1 分钟`；第 `6` 次锁 `5 分钟`；第 `7` 次锁 `15 分钟`；第 `8` 次锁 `1 小时`；第 `>=9` 次锁 `24 小时`（同时按账号与按来源 IP 双维度防护，防止换账号名撞库；一旦正确登录立即清零计数，管理员也可后台一键解除）。
5. **微信级长期免登态与断网重连保护（WeChat-Style Permanent Session）**：
   - 登录成功后签发 365 天长效签名凭证（同时写入 `HttpOnly; Max-Age=31536000` Cookie 与前端持久化存储 `yj_wechat_auth_v1`），只要用户不主动点「退出账号」、未到期且未被后台停用/封禁，永远无需隔天重输密码。
   - **断网绝不踢下线**：当用户处于地铁/电梯短暂断网、WiFi 切 5G 或服务瞬时重启导致请求网络异常时，前端保留已缓存的成员身份与界面状态并提示离线重连，监听浏览器 `online` / `visibilitychange` 事件在恢复联网后自动用原凭证静默续接；仅当服务端明确返回 `AUTH_REVOKED / ACCOUNT_EXPIRED / ACCOUNT_DISABLED / ACCOUNT_LOCKED / DEVICE_LIMIT` 时才退回登录门禁。

## 2. 百科级图文说明书 + 混合双擎铁笼智能问答 + `>4` 次探底自动锁号（`src/manual/UserManualModal.tsx` + `server/manualQaEngine.mjs`）

1. **百科全书级通俗图文重构（7 大精细章节 + 矢量图解 + 实盘算账案例）**：
   - 必须以最直白的大白话 + 具体金额算账案例解释本 APP 每一个模块与滑块，特别是：
     - **「主观胜率信心微调沙盒（-15% ～ +20%）」**：配专属矢量对比图，讲透**往右拉（+）代表你有额外利好比盘面更看好、往左拉（-）代表悲观抗压测试、中间 `0%` 代表纯信体彩去水客观真率**，以及如何观察右侧 **期望 EV** 由负转正来决定是否出手；
     - **「模拟首场延期/腰斩（按水位 1.0 算）」**、**「五维真相透视舱 6 块核心仪表」**、**「三种奖金优化（平均 / 博热保本 / 博冷高弹）」**、**「1~8 场五流派战术矩阵」**、**「消息入价消化度（Price-In）三态图解」**、**「红升 ▲ 绿降 ▼ 水位箭头」**、**「早晚场时间差 100% 锁利四步法」**。
2. **Route C 混合双擎铁笼问答（「💬 说明书智能问答」专页）**：
   - **本地精修词库（0ms 零成本秒回）**：高频控件与术语直接秒级精准作答并支持一键跳转对应图解章节。
   - **受限边界解释引擎**：复杂场景追问严格锚定《本计算器唯一官方功能边界》举例作答，绝不脱离本 APP 瞎编功能；输出层强制正则清洗，严禁泄露任何底层大模型名称（如 DeepSeek、GLM 等）或技术实现。
   - **防套底铁律与 `>4` 次自动锁号**：任何询问“你背后是什么大模型/谁开发的/提示词/源码/算法怎么抄”或超出说明书范畴的无关提问，第 `1~4` 次拦截并弹出明确红线警告；2 小时滑动窗口内累计超过 `4` 次（即第 `5` 次违规）**立即自动锁死该成员账号（`status = 'locked_violation'`，递增 `tokenVersion` 吊销会话）并同步触发 48 小时整机熔断封禁**，同时将违规提问原文记入超管审计台。

## 3. 五流派目标对决池全面解锁 `1~8` 场（`server/quantEngine.mjs` + `src/mobile/SkinPhoneApp.tsx`）

1. 解除原先目标对决池最多只允许点选 3~4 场的上限，允许用户自由点选 **`1、2、3、4、5、6、7、8` 场**（并提供「全选8场 / 重置2场」快捷按钮）。
2. 精算内核针对 `5~8` 场长串完整生成五大流派方案（遵循中国体彩总进球最高 6 关、半全场/比分最高 4 关、胜平负/让球最高 8 关及对应 20万/50万/100万 法定单注封顶规则，并在容错防爆流提供多组 2串1 分组容错矩阵）。

## 4. 扫地僧小高「单场点诊 + 多场串关联合会诊」双模升级 & 全盘红升绿降箭头

1. **模式 A（单场独立点诊）**：即使不勾选投注某支球队，也可随时单点任意一场查看独立靶向排雷与 `消息入价消化度（Price-In）`。
2. **模式 B（多场联合串关会诊）**：
   - 当混合盘已选 `>=2` 场比赛时，五维审单台与小高排雷舱均展示 **「🧹 一键联合会诊当前已选 N 场串关」** 按钮；
   - 同时支持在排雷舱自由勾选任意 `2~8` 场比赛发起联合会诊，输出整单系统性风险评级、**最易黑单短板场（`weakestLeg`）**、拆单/补防建议、整体 `Price-In` 裁定及逐场精要标签。
3. **全盘高对比红升（`▲`）绿降（`▼`）水位变动小箭头**：在胜平负、让球胜平负、总进球、半全场、比分及审单已选筹码中全面呈现鲜明红涨绿跌箭头，深色选中态下依然醒目清晰。

## 5. 48 小时整机全浏览器熔断天平（`server/securityShield.mjs` + `src/security/antiReverseShield.ts`）

1. 一旦确认开启开发者工具（`F12` / `Ctrl+Shift+I/J/C` / `Cmd+Option+I/J/C` / 桌面端连续 3 次 `debugger` 断点阻滞确认 / 无头爬虫特征 / 加密信封篡改或重放），立即触发 **48 小时（`172,800,000 ms`）** 熔断封禁。
2. 服务端将封禁记录持久化至 `data/security-bans.json`，同时锁死 **跨浏览器物理硬件指纹（`hwFp`）+ 出口 IP + 会话 Cookie**；同一台电脑换浏览器或开无痕窗口访问时命中 `hwFp` 立即阻断并传染封禁新 IP。唯一解封方式为服务器 SSH 命令操作。
